# Retention Summary Verification Receipts Contract

A PFEM retention summary verification receipts record should identify:

- `retention_summary_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_summary_record_id`
- `retention_dashboard_snapshot_closeout_record_id`
- `verification_state`
- `checked_summary_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_summary_ref_digest`
- `actual_summary_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
