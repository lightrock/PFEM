# Retention Terminal Permanent Closure Notice Records Contract

A PFEM retention terminal permanent closure notice records record should identify:

- `retention_terminal_permanent_closure_notice_record_id`
- `terminal_permanent_closure_notice_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_public_register_closeout_record_id`
- `retention_terminal_permanent_public_register_verification_receipt_id`
- `terminal_permanent_closure_notice_state`
- `terminal_permanent_closure_notice_scope`
- `terminal_permanent_closure_notice_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_permanent_closure_notice_ref_digest`
- `terminal_permanent_closure_notice_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
