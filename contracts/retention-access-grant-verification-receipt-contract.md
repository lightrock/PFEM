# Retention Access Grant Verification Receipts Contract

A PFEM retention access grant verification receipts record should identify:

- `retention_access_grant_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_access_grant_record_id`
- `retention_access_publication_closeout_record_id`
- `verification_state`
- `checked_access_grant_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_access_grant_ref_digest`
- `actual_access_grant_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
