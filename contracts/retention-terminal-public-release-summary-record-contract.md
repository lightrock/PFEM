# Retention Terminal Public Release Summary Records Contract

A PFEM retention terminal public release summary records record should identify:

- `retention_terminal_public_release_summary_record_id`
- `terminal_public_release_summary_kind`
- `created_time`
- `node_id`
- `retention_terminal_public_metrics_snapshot_closeout_record_id`
- `retention_terminal_public_metrics_snapshot_verification_receipt_id`
- `terminal_public_release_summary_state`
- `terminal_public_release_summary_scope`
- `terminal_public_release_summary_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_public_release_summary_ref_digest`
- `terminal_public_release_summary_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
