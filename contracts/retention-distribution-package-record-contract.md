# Retention Distribution Package Records Contract

A PFEM retention distribution package records record should identify:

- `retention_distribution_package_record_id`
- `distribution_package_kind`
- `created_time`
- `node_id`
- `retention_release_confirmation_closeout_record_id`
- `retention_release_confirmation_verification_receipt_id`
- `distribution_package_state`
- `distribution_package_scope`
- `distribution_package_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `distribution_package_ref_digest`
- `distribution_package_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
