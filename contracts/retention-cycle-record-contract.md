# Retention Cycle Records Contract

A PFEM retention cycle records record should identify:

- `retention_cycle_record_id`
- `cycle_kind`
- `created_time`
- `node_id`
- `retention_schedule_closeout_record_id`
- `cycle_state`
- `final_outcome`
- `cycle_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `cycle_ref_digest`
- `summarized_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
