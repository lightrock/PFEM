# Retention Permanent Archive Release Register Records Contract

A PFEM retention permanent archive release register records record should identify:

- `retention_permanent_archive_release_register_record_id`
- `permanent_archive_release_register_kind`
- `created_time`
- `node_id`
- `retention_permanent_archive_retention_lock_closeout_record_id`
- `retention_permanent_archive_retention_lock_verification_receipt_id`
- `permanent_archive_release_register_state`
- `permanent_archive_release_register_scope`
- `permanent_archive_release_register_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `permanent_archive_release_register_ref_digest`
- `permanent_archive_release_register_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
