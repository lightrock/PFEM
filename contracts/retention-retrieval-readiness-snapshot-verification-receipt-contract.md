# Retention Retrieval Readiness Snapshot Verification Receipts Contract

A PFEM retention retrieval readiness snapshot verification receipts record should identify:

- `retention_retrieval_readiness_snapshot_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_retrieval_readiness_snapshot_record_id`
- `retention_archive_availability_rollup_closeout_record_id`
- `verification_state`
- `checked_retrieval_readiness_snapshot_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_retrieval_readiness_snapshot_ref_digest`
- `actual_retrieval_readiness_snapshot_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
