# Retention Terminal Archival Accession Verification Receipts Contract

A PFEM retention terminal archival accession verification receipts record should identify:

- `retention_terminal_archival_accession_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_archival_accession_record_id`
- `retention_terminal_finalization_audit_closeout_record_id`
- `verification_state`
- `checked_terminal_archival_accession_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_archival_accession_ref_digest`
- `actual_terminal_archival_accession_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
