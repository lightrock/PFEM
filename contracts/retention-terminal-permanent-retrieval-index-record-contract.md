# Retention Terminal Permanent Retrieval Index Records Contract

A PFEM retention terminal permanent retrieval index records record should identify:

- `retention_terminal_permanent_retrieval_index_record_id`
- `terminal_permanent_retrieval_index_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_storage_receipt_closeout_record_id`
- `retention_terminal_permanent_storage_receipt_verification_receipt_id`
- `terminal_permanent_retrieval_index_state`
- `terminal_permanent_retrieval_index_scope`
- `terminal_permanent_retrieval_index_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_permanent_retrieval_index_ref_digest`
- `terminal_permanent_retrieval_index_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
