# Retention Release Metrics Snapshot Records Contract

A PFEM retention release metrics snapshot records record should identify:

- `retention_release_metrics_snapshot_record_id`
- `release_metrics_snapshot_kind`
- `created_time`
- `node_id`
- `retention_release_exception_summary_closeout_record_id`
- `retention_release_exception_summary_verification_receipt_id`
- `release_metrics_snapshot_state`
- `release_metrics_snapshot_scope`
- `release_metrics_snapshot_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_metrics_snapshot_ref_digest`
- `release_metrics_snapshot_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
