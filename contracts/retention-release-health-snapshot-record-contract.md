# Retention Release Health Snapshot Records Contract

A PFEM retention release health snapshot records record should identify:

- `retention_release_health_snapshot_record_id`
- `release_health_snapshot_kind`
- `created_time`
- `node_id`
- `retention_access_audit_snapshot_closeout_record_id`
- `retention_access_audit_snapshot_verification_receipt_id`
- `release_health_snapshot_state`
- `release_health_snapshot_scope`
- `release_health_snapshot_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_health_snapshot_ref_digest`
- `release_health_snapshot_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
