# Retention Terminal Rollup Report Records Contract

A PFEM retention terminal rollup report records record should identify:

- `retention_terminal_rollup_report_record_id`
- `terminal_rollup_report_kind`
- `created_time`
- `node_id`
- `retention_terminal_integrity_certificate_closeout_record_id`
- `retention_terminal_integrity_certificate_verification_receipt_id`
- `terminal_rollup_report_state`
- `terminal_rollup_report_scope`
- `terminal_rollup_report_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_rollup_report_ref_digest`
- `terminal_rollup_report_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
