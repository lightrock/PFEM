# Retention Release Access Index Verification Receipts Contract

A PFEM retention release access index verification receipts record should identify:

- `retention_release_access_index_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_release_access_index_record_id`
- `retention_public_access_register_closeout_record_id`
- `verification_state`
- `checked_release_access_index_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_release_access_index_ref_digest`
- `actual_release_access_index_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
