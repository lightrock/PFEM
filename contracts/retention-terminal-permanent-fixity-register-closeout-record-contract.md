# Retention Terminal Permanent Fixity Register Closeout Records Contract

A PFEM retention terminal permanent fixity register closeout records record should identify:

- `retention_terminal_permanent_fixity_register_closeout_record_id`
- `closeout_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_fixity_register_verification_receipt_id`
- `retention_terminal_permanent_fixity_register_record_id`
- `closeout_state`
- `outcome`
- `closed_refs`
- `subject_refs`
- `basis_refs`
- `closed_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
