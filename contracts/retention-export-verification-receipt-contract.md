# Retention Export Verification Receipts Contract

A PFEM retention export verification receipts record should identify:

- `retention_export_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_export_record_id`
- `retention_summary_closeout_record_id`
- `verification_state`
- `checked_export_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_export_ref_digest`
- `actual_export_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
