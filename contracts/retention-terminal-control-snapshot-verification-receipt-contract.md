# Retention Terminal Control Snapshot Verification Receipts Contract

A PFEM retention terminal control snapshot verification receipts record should identify:

- `retention_terminal_control_snapshot_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_control_snapshot_record_id`
- `retention_terminal_policy_attestation_closeout_record_id`
- `verification_state`
- `checked_terminal_control_snapshot_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_control_snapshot_ref_digest`
- `actual_terminal_control_snapshot_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
