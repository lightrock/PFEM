# Retention Release Confirmation Records Contract

A PFEM retention release confirmation records record should identify:

- `retention_release_confirmation_record_id`
- `release_confirmation_kind`
- `created_time`
- `node_id`
- `retention_release_acknowledgement_closeout_record_id`
- `retention_release_acknowledgement_verification_receipt_id`
- `release_confirmation_state`
- `release_confirmation_scope`
- `release_confirmation_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_confirmation_ref_digest`
- `release_confirmation_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
