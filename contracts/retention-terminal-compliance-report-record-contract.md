# Retention Terminal Compliance Report Records Contract

A PFEM retention terminal compliance report records record should identify:

- `retention_terminal_compliance_report_record_id`
- `terminal_compliance_report_kind`
- `created_time`
- `node_id`
- `retention_terminal_control_snapshot_closeout_record_id`
- `retention_terminal_control_snapshot_verification_receipt_id`
- `terminal_compliance_report_state`
- `terminal_compliance_report_scope`
- `terminal_compliance_report_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_compliance_report_ref_digest`
- `terminal_compliance_report_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
