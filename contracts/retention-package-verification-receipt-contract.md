# Retention Package Verification Receipts Contract

A PFEM retention package verification receipts record should identify:

- `retention_package_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_package_record_id`
- `retention_acceptance_closeout_record_id`
- `verification_state`
- `checked_package_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_package_ref_digest`
- `actual_package_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
