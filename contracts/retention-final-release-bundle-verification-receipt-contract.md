# Retention Final Release Bundle Verification Receipts Contract

A PFEM retention final release bundle verification receipts record should identify:

- `retention_final_release_bundle_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_final_release_bundle_record_id`
- `retention_public_record_index_closeout_record_id`
- `verification_state`
- `checked_final_release_bundle_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_final_release_bundle_ref_digest`
- `actual_final_release_bundle_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
