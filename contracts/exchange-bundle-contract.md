# Exchange Bundle Contract

A PFEM exchange bundle should identify:

- `bundle_id`
- `bundle_kind`
- `producer_node_id`
- `recipient_node_ids`
- `sharing_scope`
- `handling_label`
- `redaction_state`
- `retention_class`
- `disposition_state`
- `included_record_refs`
- `included_artifact_paths`
- `purpose`

A bundle should include enough context for another node or reviewer to understand the handoff without guessing.
