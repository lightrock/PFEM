# Retention Seal Verification Receipts Contract

A PFEM retention seal verification receipts record should identify:

- `retention_seal_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_seal_record_id`
- `retention_attestation_closeout_record_id`
- `verification_state`
- `checked_seal_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_seal_ref_digest`
- `actual_seal_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
