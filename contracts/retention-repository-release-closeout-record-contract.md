# Retention Repository Release Closeout Records Contract

A PFEM retention repository release closeout records record should identify:

- `retention_repository_release_closeout_record_id`
- `closeout_kind`
- `created_time`
- `node_id`
- `retention_repository_release_verification_receipt_id`
- `retention_repository_release_record_id`
- `closeout_state`
- `outcome`
- `closed_refs`
- `subject_refs`
- `basis_refs`
- `closed_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
