# Retention Release Acceptance Verification Receipts Contract

A PFEM retention release acceptance verification receipts record should identify:

- `retention_release_acceptance_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_release_acceptance_record_id`
- `retention_terminal_access_notice_closeout_record_id`
- `verification_state`
- `checked_release_acceptance_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_release_acceptance_ref_digest`
- `actual_release_acceptance_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
