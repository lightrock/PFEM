# Retention Public Release Receipt Verification Receipts Contract

A PFEM retention public release receipt verification receipts record should identify:

- `retention_public_release_receipt_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_public_release_receipt_record_id`
- `retention_consumer_availability_notice_closeout_record_id`
- `verification_state`
- `checked_public_release_receipt_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_public_release_receipt_ref_digest`
- `actual_public_release_receipt_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
