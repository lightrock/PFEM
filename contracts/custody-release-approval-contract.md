# Custody Release Approvals Contract

A PFEM custody release approvals record should identify:

- `custody_release_approval_id`
- `approval_kind`
- `created_time`
- `node_id`
- `custody_release_request_id`
- `custody_ledger_verification_receipt_id`
- `approval_state`
- `approved_release_scope`
- `approved_refs`
- `basis_refs`
- `approved_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
