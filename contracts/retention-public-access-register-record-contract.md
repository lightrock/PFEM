# Retention Public Access Register Records Contract

A PFEM retention public access register records record should identify:

- `retention_public_access_register_record_id`
- `public_access_register_kind`
- `created_time`
- `node_id`
- `retention_distribution_closure_notice_closeout_record_id`
- `retention_distribution_closure_notice_verification_receipt_id`
- `public_access_register_state`
- `public_access_register_scope`
- `public_access_register_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `public_access_register_ref_digest`
- `public_access_register_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
