# Retention Public Release Receipt Closeout Records Contract

A PFEM retention public release receipt closeout records record should identify:

- `retention_public_release_receipt_closeout_record_id`
- `closeout_kind`
- `created_time`
- `node_id`
- `retention_public_release_receipt_verification_receipt_id`
- `retention_public_release_receipt_record_id`
- `closeout_state`
- `outcome`
- `closed_refs`
- `subject_refs`
- `basis_refs`
- `closed_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
