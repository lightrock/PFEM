# Retention Terminal Evidence Index Records Contract

A PFEM retention terminal evidence index records record should identify:

- `retention_terminal_evidence_index_record_id`
- `terminal_evidence_index_kind`
- `created_time`
- `node_id`
- `retention_terminal_final_closeout_closeout_record_id`
- `retention_terminal_final_closeout_verification_receipt_id`
- `terminal_evidence_index_state`
- `terminal_evidence_index_scope`
- `terminal_evidence_index_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_evidence_index_ref_digest`
- `terminal_evidence_index_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
