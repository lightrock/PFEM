# Retention Release Terminal Report Records Contract

A PFEM retention release terminal report records record should identify:

- `retention_release_terminal_report_record_id`
- `release_terminal_report_kind`
- `created_time`
- `node_id`
- `retention_release_metrics_snapshot_closeout_record_id`
- `retention_release_metrics_snapshot_verification_receipt_id`
- `release_terminal_report_state`
- `release_terminal_report_scope`
- `release_terminal_report_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_terminal_report_ref_digest`
- `release_terminal_report_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
