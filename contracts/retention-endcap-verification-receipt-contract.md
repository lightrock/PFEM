# Retention Endcap Verification Receipts Contract

A PFEM retention endcap verification receipts record should identify:

- `retention_endcap_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_endcap_record_id`
- `retention_archive_anchor_closeout_record_id`
- `verification_state`
- `checked_endcap_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_endcap_ref_digest`
- `actual_endcap_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
