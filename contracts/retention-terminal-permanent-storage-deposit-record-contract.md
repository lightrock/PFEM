# Retention Terminal Permanent Storage Deposit Records Contract

A PFEM retention terminal permanent storage deposit records record should identify:

- `retention_terminal_permanent_storage_deposit_record_id`
- `terminal_permanent_storage_deposit_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_archive_manifest_closeout_record_id`
- `retention_terminal_permanent_archive_manifest_verification_receipt_id`
- `terminal_permanent_storage_deposit_state`
- `terminal_permanent_storage_deposit_scope`
- `terminal_permanent_storage_deposit_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_permanent_storage_deposit_ref_digest`
- `terminal_permanent_storage_deposit_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
