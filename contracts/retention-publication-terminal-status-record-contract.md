# Retention Publication Terminal Status Records Contract

A PFEM retention publication terminal status records record should identify:

- `retention_publication_terminal_status_record_id`
- `publication_terminal_status_kind`
- `created_time`
- `node_id`
- `retention_terminal_publication_bundle_closeout_record_id`
- `retention_terminal_publication_bundle_verification_receipt_id`
- `publication_terminal_status_state`
- `publication_terminal_status_scope`
- `publication_terminal_status_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `publication_terminal_status_ref_digest`
- `publication_terminal_status_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
