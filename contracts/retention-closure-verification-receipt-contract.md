# Retention Closure Verification Receipts Contract

A PFEM retention closure verification receipts record should identify:

- `retention_closure_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_closure_record_id`
- `retention_registry_closeout_record_id`
- `verification_state`
- `checked_closure_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_closure_ref_digest`
- `actual_closure_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
