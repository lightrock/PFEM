# Custody Release Chain Records Contract

A PFEM custody release chain records record should identify:

- `custody_release_chain_record_id`
- `chain_kind`
- `created_time`
- `node_id`
- `start_ref`
- `terminal_ref`
- `chain_state`
- `final_outcome`
- `chain_refs`
- `released_refs`
- `basis_refs`
- `digest_algorithm`
- `chain_ref_digest`
- `summarized_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
