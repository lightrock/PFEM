# Retention Public Release Receipt Records Contract

A PFEM retention public release receipt records record should identify:

- `retention_public_release_receipt_record_id`
- `public_release_receipt_kind`
- `created_time`
- `node_id`
- `retention_consumer_availability_notice_closeout_record_id`
- `retention_consumer_availability_notice_verification_receipt_id`
- `public_release_receipt_state`
- `public_release_receipt_scope`
- `public_release_receipt_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `public_release_receipt_ref_digest`
- `public_release_receipt_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
