# Retention Release Usage Summary Records Contract

A PFEM retention release usage summary records record should identify:

- `retention_release_usage_summary_record_id`
- `release_usage_summary_kind`
- `created_time`
- `node_id`
- `retention_release_health_snapshot_closeout_record_id`
- `retention_release_health_snapshot_verification_receipt_id`
- `release_usage_summary_state`
- `release_usage_summary_scope`
- `release_usage_summary_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_usage_summary_ref_digest`
- `release_usage_summary_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
