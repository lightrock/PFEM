# Retention Release Exception Summary Records Contract

A PFEM retention release exception summary records record should identify:

- `retention_release_exception_summary_record_id`
- `release_exception_summary_kind`
- `created_time`
- `node_id`
- `retention_release_exception_register_closeout_record_id`
- `retention_release_exception_register_verification_receipt_id`
- `release_exception_summary_state`
- `release_exception_summary_scope`
- `release_exception_summary_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_exception_summary_ref_digest`
- `release_exception_summary_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
