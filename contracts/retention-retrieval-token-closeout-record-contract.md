# Retention Retrieval Token Closeout Records Contract

A PFEM retention retrieval token closeout records record should identify:

- `retention_retrieval_token_closeout_record_id`
- `closeout_kind`
- `created_time`
- `node_id`
- `retention_retrieval_token_verification_receipt_id`
- `retention_retrieval_token_record_id`
- `closeout_state`
- `outcome`
- `closed_refs`
- `subject_refs`
- `basis_refs`
- `closed_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
