# Retention Permanent Archive Handoff Package Records Contract

A PFEM retention permanent archive handoff package records record should identify:

- `retention_permanent_archive_handoff_package_record_id`
- `permanent_archive_handoff_package_kind`
- `created_time`
- `node_id`
- `retention_permanent_archive_accession_summary_closeout_record_id`
- `retention_permanent_archive_accession_summary_verification_receipt_id`
- `permanent_archive_handoff_package_state`
- `permanent_archive_handoff_package_scope`
- `permanent_archive_handoff_package_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `permanent_archive_handoff_package_ref_digest`
- `permanent_archive_handoff_package_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
