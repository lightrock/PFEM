# Retention Terminal Archive Report Records Contract

A PFEM retention terminal archive report records record should identify:

- `retention_terminal_archive_report_record_id`
- `terminal_archive_report_kind`
- `created_time`
- `node_id`
- `retention_terminal_exception_summary_closeout_record_id`
- `retention_terminal_exception_summary_verification_receipt_id`
- `terminal_archive_report_state`
- `terminal_archive_report_scope`
- `terminal_archive_report_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_archive_report_ref_digest`
- `terminal_archive_report_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
