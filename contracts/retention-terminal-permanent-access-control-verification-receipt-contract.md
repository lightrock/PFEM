# Retention Terminal Permanent Access Control Verification Receipts Contract

A PFEM retention terminal permanent access control verification receipts record should identify:

- `retention_terminal_permanent_access_control_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_access_control_record_id`
- `retention_terminal_permanent_retrieval_index_closeout_record_id`
- `verification_state`
- `checked_terminal_permanent_access_control_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_permanent_access_control_ref_digest`
- `actual_terminal_permanent_access_control_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
