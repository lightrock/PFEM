# Retention Release Terminal Report Closeout Records Contract

A PFEM retention release terminal report closeout records record should identify:

- `retention_release_terminal_report_closeout_record_id`
- `closeout_kind`
- `created_time`
- `node_id`
- `retention_release_terminal_report_verification_receipt_id`
- `retention_release_terminal_report_record_id`
- `closeout_state`
- `outcome`
- `closed_refs`
- `subject_refs`
- `basis_refs`
- `closed_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
