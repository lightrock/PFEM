# Retention Terminal Manifest Attestation Verification Receipts Contract

A PFEM retention terminal manifest attestation verification receipts record should identify:

- `retention_terminal_manifest_attestation_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_manifest_attestation_record_id`
- `retention_terminal_evidence_index_closeout_record_id`
- `verification_state`
- `checked_terminal_manifest_attestation_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_manifest_attestation_ref_digest`
- `actual_terminal_manifest_attestation_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
