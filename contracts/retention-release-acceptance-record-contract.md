# Retention Release Acceptance Records Contract

A PFEM retention release acceptance records record should identify:

- `retention_release_acceptance_record_id`
- `release_acceptance_kind`
- `created_time`
- `node_id`
- `retention_terminal_access_notice_closeout_record_id`
- `retention_terminal_access_notice_verification_receipt_id`
- `release_acceptance_state`
- `release_acceptance_scope`
- `release_acceptance_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_acceptance_ref_digest`
- `release_acceptance_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
