# Retention Terminal Public Metrics Snapshot Records Contract

A PFEM retention terminal public metrics snapshot records record should identify:

- `retention_terminal_public_metrics_snapshot_record_id`
- `terminal_public_metrics_snapshot_kind`
- `created_time`
- `node_id`
- `retention_terminal_public_audit_snapshot_closeout_record_id`
- `retention_terminal_public_audit_snapshot_verification_receipt_id`
- `terminal_public_metrics_snapshot_state`
- `terminal_public_metrics_snapshot_scope`
- `terminal_public_metrics_snapshot_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_public_metrics_snapshot_ref_digest`
- `terminal_public_metrics_snapshot_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
