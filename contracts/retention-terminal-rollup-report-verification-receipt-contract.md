# Retention Terminal Rollup Report Verification Receipts Contract

A PFEM retention terminal rollup report verification receipts record should identify:

- `retention_terminal_rollup_report_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_rollup_report_record_id`
- `retention_terminal_integrity_certificate_closeout_record_id`
- `verification_state`
- `checked_terminal_rollup_report_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_rollup_report_ref_digest`
- `actual_terminal_rollup_report_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
