# Retention Terminal Public Digest Verification Receipts Contract

A PFEM retention terminal public digest verification receipts record should identify:

- `retention_terminal_public_digest_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_public_digest_record_id`
- `retention_terminal_public_index_closeout_record_id`
- `verification_state`
- `checked_terminal_public_digest_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_public_digest_ref_digest`
- `actual_terminal_public_digest_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
