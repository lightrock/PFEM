# Retention Publication Closure Certificate Verification Receipts Contract

A PFEM retention publication closure certificate verification receipts record should identify:

- `retention_publication_closure_certificate_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_publication_closure_certificate_record_id`
- `retention_publication_completion_closeout_record_id`
- `verification_state`
- `checked_publication_closure_certificate_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_publication_closure_certificate_ref_digest`
- `actual_publication_closure_certificate_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
