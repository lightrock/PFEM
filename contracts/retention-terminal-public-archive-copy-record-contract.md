# Retention Terminal Public Archive Copy Records Contract

A PFEM retention terminal public archive copy records record should identify:

- `retention_terminal_public_archive_copy_record_id`
- `terminal_public_archive_copy_kind`
- `created_time`
- `node_id`
- `retention_terminal_public_digest_closeout_record_id`
- `retention_terminal_public_digest_verification_receipt_id`
- `terminal_public_archive_copy_state`
- `terminal_public_archive_copy_scope`
- `terminal_public_archive_copy_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_public_archive_copy_ref_digest`
- `terminal_public_archive_copy_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
