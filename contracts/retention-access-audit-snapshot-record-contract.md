# Retention Access Audit Snapshot Records Contract

A PFEM retention access audit snapshot records record should identify:

- `retention_access_audit_snapshot_record_id`
- `access_audit_snapshot_kind`
- `created_time`
- `node_id`
- `retention_distribution_receipt_closeout_record_id`
- `retention_distribution_receipt_verification_receipt_id`
- `access_audit_snapshot_state`
- `access_audit_snapshot_scope`
- `access_audit_snapshot_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `access_audit_snapshot_ref_digest`
- `access_audit_snapshot_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
