# Retention Final Release Bundle Records Contract

A PFEM retention final release bundle records record should identify:

- `retention_final_release_bundle_record_id`
- `final_release_bundle_kind`
- `created_time`
- `node_id`
- `retention_public_record_index_closeout_record_id`
- `retention_public_record_index_verification_receipt_id`
- `final_release_bundle_state`
- `final_release_bundle_scope`
- `final_release_bundle_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `final_release_bundle_ref_digest`
- `final_release_bundle_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
