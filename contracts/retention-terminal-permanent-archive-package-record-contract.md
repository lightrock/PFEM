# Retention Terminal Permanent Archive Package Records Contract

A PFEM retention terminal permanent archive package records record should identify:

- `retention_terminal_permanent_archive_package_record_id`
- `terminal_permanent_archive_package_kind`
- `created_time`
- `node_id`
- `retention_terminal_archival_accession_closeout_record_id`
- `retention_terminal_archival_accession_verification_receipt_id`
- `terminal_permanent_archive_package_state`
- `terminal_permanent_archive_package_scope`
- `terminal_permanent_archive_package_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_permanent_archive_package_ref_digest`
- `terminal_permanent_archive_package_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
