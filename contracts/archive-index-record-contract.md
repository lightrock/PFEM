# Archive Index Records Contract

A PFEM archive index records record should identify:

- `archive_index_record_id`
- `index_kind`
- `created_time`
- `node_id`
- `archive_chain_verification_receipt_id`
- `archive_chain_record_id`
- `index_state`
- `index_scope`
- `indexed_refs`
- `index_entries`
- `basis_refs`
- `digest_algorithm`
- `indexed_ref_digest`
- `indexed_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
