# Archive Index Verification Receipts Contract

A PFEM archive index verification receipts record should identify:

- `archive_index_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `archive_index_record_id`
- `archive_chain_verification_receipt_id`
- `verification_state`
- `checked_indexed_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_indexed_ref_digest`
- `actual_indexed_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
