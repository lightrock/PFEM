# Retention Release Closeout Summary Records Contract

A PFEM retention release closeout summary records record should identify:

- `retention_release_closeout_summary_record_id`
- `release_closeout_summary_kind`
- `created_time`
- `node_id`
- `retention_retention_exposure_report_closeout_record_id`
- `retention_retention_exposure_report_verification_receipt_id`
- `release_closeout_summary_state`
- `release_closeout_summary_scope`
- `release_closeout_summary_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_closeout_summary_ref_digest`
- `release_closeout_summary_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
