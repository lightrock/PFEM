# Retention Terminal Control Snapshot Records Contract

A PFEM retention terminal control snapshot records record should identify:

- `retention_terminal_control_snapshot_record_id`
- `terminal_control_snapshot_kind`
- `created_time`
- `node_id`
- `retention_terminal_policy_attestation_closeout_record_id`
- `retention_terminal_policy_attestation_verification_receipt_id`
- `terminal_control_snapshot_state`
- `terminal_control_snapshot_scope`
- `terminal_control_snapshot_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_control_snapshot_ref_digest`
- `terminal_control_snapshot_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
