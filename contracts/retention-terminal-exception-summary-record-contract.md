# Retention Terminal Exception Summary Records Contract

A PFEM retention terminal exception summary records record should identify:

- `retention_terminal_exception_summary_record_id`
- `terminal_exception_summary_kind`
- `created_time`
- `node_id`
- `retention_terminal_consumer_summary_closeout_record_id`
- `retention_terminal_consumer_summary_verification_receipt_id`
- `terminal_exception_summary_state`
- `terminal_exception_summary_scope`
- `terminal_exception_summary_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_exception_summary_ref_digest`
- `terminal_exception_summary_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
