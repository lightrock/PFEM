# Retention Report Records Contract

A PFEM retention report records record should identify:

- `retention_report_record_id`
- `report_kind`
- `created_time`
- `node_id`
- `retention_rollup_closeout_record_id`
- `retention_rollup_verification_receipt_id`
- `report_state`
- `report_scope`
- `reported_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `reported_ref_digest`
- `reported_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
