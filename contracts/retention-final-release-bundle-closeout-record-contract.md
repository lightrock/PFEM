# Retention Final Release Bundle Closeout Records Contract

A PFEM retention final release bundle closeout records record should identify:

- `retention_final_release_bundle_closeout_record_id`
- `closeout_kind`
- `created_time`
- `node_id`
- `retention_final_release_bundle_verification_receipt_id`
- `retention_final_release_bundle_record_id`
- `closeout_state`
- `outcome`
- `closed_refs`
- `subject_refs`
- `basis_refs`
- `closed_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
