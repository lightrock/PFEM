# Retention Release Metrics Snapshot Verification Receipts Contract

A PFEM retention release metrics snapshot verification receipts record should identify:

- `retention_release_metrics_snapshot_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_release_metrics_snapshot_record_id`
- `retention_release_exception_summary_closeout_record_id`
- `verification_state`
- `checked_release_metrics_snapshot_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_release_metrics_snapshot_ref_digest`
- `actual_release_metrics_snapshot_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
