# Retention Terminal Permanent Public Register Records Contract

A PFEM retention terminal permanent public register records record should identify:

- `retention_terminal_permanent_public_register_record_id`
- `terminal_permanent_public_register_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_custody_transfer_closeout_record_id`
- `retention_terminal_permanent_custody_transfer_verification_receipt_id`
- `terminal_permanent_public_register_state`
- `terminal_permanent_public_register_scope`
- `terminal_permanent_public_register_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_permanent_public_register_ref_digest`
- `terminal_permanent_public_register_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
