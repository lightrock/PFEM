# Retention Release Acknowledgement Records Contract

A PFEM retention release acknowledgement records record should identify:

- `retention_release_acknowledgement_record_id`
- `release_acknowledgement_kind`
- `created_time`
- `node_id`
- `retention_availability_notice_closeout_record_id`
- `retention_availability_notice_verification_receipt_id`
- `release_acknowledgement_state`
- `release_acknowledgement_scope`
- `release_acknowledgement_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_acknowledgement_ref_digest`
- `release_acknowledgement_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
