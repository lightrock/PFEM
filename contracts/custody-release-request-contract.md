# Custody Release Requests Contract

A PFEM custody release requests record should identify:

- `custody_release_request_id`
- `request_kind`
- `created_time`
- `node_id`
- `custody_ledger_verification_receipt_id`
- `custody_ledger_record_id`
- `source_workflow_kind`
- `source_closeout_ref`
- `request_state`
- `release_scope`
- `requested_refs`
- `basis_refs`
- `requested_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
