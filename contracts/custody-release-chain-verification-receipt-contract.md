# Custody Release Chain Verification Receipts Contract

A PFEM custody release chain verification receipts record should identify:

- `custody_release_chain_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `custody_release_chain_record_id`
- `terminal_ref`
- `verification_state`
- `checked_chain_refs`
- `checked_released_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_chain_ref_digest`
- `actual_chain_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
