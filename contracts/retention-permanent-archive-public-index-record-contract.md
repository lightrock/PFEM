# Retention Permanent Archive Public Index Records Contract

A PFEM retention permanent archive public index records record should identify:

- `retention_permanent_archive_public_index_record_id`
- `permanent_archive_public_index_kind`
- `created_time`
- `node_id`
- `retention_permanent_archive_access_register_closeout_record_id`
- `retention_permanent_archive_access_register_verification_receipt_id`
- `permanent_archive_public_index_state`
- `permanent_archive_public_index_scope`
- `permanent_archive_public_index_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `permanent_archive_public_index_ref_digest`
- `permanent_archive_public_index_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
