# Retention Terminal Permanent Retrieval Index Closeout Records Contract

A PFEM retention terminal permanent retrieval index closeout records record should identify:

- `retention_terminal_permanent_retrieval_index_closeout_record_id`
- `closeout_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_retrieval_index_verification_receipt_id`
- `retention_terminal_permanent_retrieval_index_record_id`
- `closeout_state`
- `outcome`
- `closed_refs`
- `subject_refs`
- `basis_refs`
- `closed_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
