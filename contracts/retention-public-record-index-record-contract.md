# Retention Public Record Index Records Contract

A PFEM retention public record index records record should identify:

- `retention_public_record_index_record_id`
- `public_record_index_kind`
- `created_time`
- `node_id`
- `retention_release_closeout_summary_closeout_record_id`
- `retention_release_closeout_summary_verification_receipt_id`
- `public_record_index_state`
- `public_record_index_scope`
- `public_record_index_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `public_record_index_ref_digest`
- `public_record_index_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
