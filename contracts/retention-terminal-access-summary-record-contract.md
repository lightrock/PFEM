# Retention Terminal Access Summary Records Contract

A PFEM retention terminal access summary records record should identify:

- `retention_terminal_access_summary_record_id`
- `terminal_access_summary_kind`
- `created_time`
- `node_id`
- `retention_terminal_distribution_summary_closeout_record_id`
- `retention_terminal_distribution_summary_verification_receipt_id`
- `terminal_access_summary_state`
- `terminal_access_summary_scope`
- `terminal_access_summary_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_access_summary_ref_digest`
- `terminal_access_summary_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
