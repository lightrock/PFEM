# Retention Action Verification Receipts Contract

A PFEM retention action verification receipts record should identify:

- `retention_action_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_action_receipt_id`
- `retention_decision_approval_id`
- `verification_state`
- `checked_action_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_action_ref_digest`
- `actual_action_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
