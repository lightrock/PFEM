# Custody Release Verification Receipts Contract

A PFEM custody release verification receipts record should identify:

- `custody_release_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `custody_release_receipt_id`
- `custody_release_approval_id`
- `custody_release_request_id`
- `verification_state`
- `checked_released_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_released_ref_digest`
- `actual_released_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
