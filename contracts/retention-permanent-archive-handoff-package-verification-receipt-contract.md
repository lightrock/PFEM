A PFEM retention permanent archive handoff package verification receipts record should identify:

- `retention_permanent_archive_handoff_package_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_permanent_archive_handoff_package_record_id`
- `retention_permanent_archive_accession_summary_closeout_record_id`
- `verification_state`
- `checked_permanent_archive_handoff_package_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_permanent_archive_handoff_package_ref_digest`
- `actual_permanent_archive_handoff_package_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
