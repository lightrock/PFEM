# Retention Terminal Access Notice Verification Receipts Contract

A PFEM retention terminal access notice verification receipts record should identify:

- `retention_terminal_access_notice_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_access_notice_record_id`
- `retention_final_release_bundle_closeout_record_id`
- `verification_state`
- `checked_terminal_access_notice_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_access_notice_ref_digest`
- `actual_terminal_access_notice_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
