# Retention Publication Terminal Status Verification Receipts Contract

A PFEM retention publication terminal status verification receipts record should identify:

- `retention_publication_terminal_status_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_publication_terminal_status_record_id`
- `retention_terminal_publication_bundle_closeout_record_id`
- `verification_state`
- `checked_publication_terminal_status_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_publication_terminal_status_ref_digest`
- `actual_publication_terminal_status_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
