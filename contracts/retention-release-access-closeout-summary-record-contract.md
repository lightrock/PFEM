# Retention Release Access Closeout Summary Records Contract

A PFEM retention release access closeout summary records record should identify:

- `retention_release_access_closeout_summary_record_id`
- `release_access_closeout_summary_kind`
- `created_time`
- `node_id`
- `retention_release_access_verification_summary_closeout_record_id`
- `retention_release_access_verification_summary_verification_receipt_id`
- `release_access_closeout_summary_state`
- `release_access_closeout_summary_scope`
- `release_access_closeout_summary_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_access_closeout_summary_ref_digest`
- `release_access_closeout_summary_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
