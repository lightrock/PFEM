# Retention Permanent Archive Public Release Notice Records Contract

A PFEM retention permanent archive public release notice records record should identify:

- `retention_permanent_archive_public_release_notice_record_id`
- `permanent_archive_public_release_notice_kind`
- `created_time`
- `node_id`
- `retention_permanent_archive_release_closeout_summary_closeout_record_id`
- `retention_permanent_archive_release_closeout_summary_verification_receipt_id`
- `permanent_archive_public_release_notice_state`
- `permanent_archive_public_release_notice_scope`
- `permanent_archive_public_release_notice_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `permanent_archive_public_release_notice_ref_digest`
- `permanent_archive_public_release_notice_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
