# Retention Distribution Package Closeout Records Contract

A PFEM retention distribution package closeout records record should identify:

- `retention_distribution_package_closeout_record_id`
- `closeout_kind`
- `created_time`
- `node_id`
- `retention_distribution_package_verification_receipt_id`
- `retention_distribution_package_record_id`
- `closeout_state`
- `outcome`
- `closed_refs`
- `subject_refs`
- `basis_refs`
- `closed_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
