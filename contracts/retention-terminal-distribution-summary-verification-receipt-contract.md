# Retention Terminal Distribution Summary Verification Receipts Contract

A PFEM retention terminal distribution summary verification receipts record should identify:

- `retention_terminal_distribution_summary_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_distribution_summary_record_id`
- `retention_terminal_public_release_summary_closeout_record_id`
- `verification_state`
- `checked_terminal_distribution_summary_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_distribution_summary_ref_digest`
- `actual_terminal_distribution_summary_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
