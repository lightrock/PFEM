# Retention Final Index Verification Receipts Contract

A PFEM retention final index verification receipts record should identify:

- `retention_final_index_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_final_index_record_id`
- `retention_endcap_closeout_record_id`
- `verification_state`
- `checked_final_index_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_final_index_ref_digest`
- `actual_final_index_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
