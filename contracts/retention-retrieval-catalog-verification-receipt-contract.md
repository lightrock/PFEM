# Retention Retrieval Catalog Verification Receipts Contract

A PFEM retention retrieval catalog verification receipts record should identify:

- `retention_retrieval_catalog_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_retrieval_catalog_record_id`
- `retention_access_ledger_closeout_record_id`
- `verification_state`
- `checked_retrieval_catalog_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_retrieval_catalog_ref_digest`
- `actual_retrieval_catalog_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
