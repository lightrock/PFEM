# Retention Release Exception Register Records Contract

A PFEM retention release exception register records record should identify:

- `retention_release_exception_register_record_id`
- `release_exception_register_kind`
- `created_time`
- `node_id`
- `retention_public_release_receipt_closeout_record_id`
- `retention_public_release_receipt_verification_receipt_id`
- `release_exception_register_state`
- `release_exception_register_scope`
- `release_exception_register_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_exception_register_ref_digest`
- `release_exception_register_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
