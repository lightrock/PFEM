# Retention Action Receipts Contract

A PFEM retention action receipts record should identify:

- `retention_action_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_decision_approval_id`
- `retention_decision_record_id`
- `action_state`
- `action`
- `action_scope`
- `acted_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `action_ref_digest`
- `acted_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
