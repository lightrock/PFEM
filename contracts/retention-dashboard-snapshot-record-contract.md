# Retention Dashboard Snapshot Records Contract

A PFEM retention dashboard snapshot records record should identify:

- `retention_dashboard_snapshot_record_id`
- `snapshot_kind`
- `created_time`
- `node_id`
- `retention_publication_closeout_record_id`
- `retention_status_snapshot_verification_receipt_id`
- `snapshot_state`
- `dashboard_status`
- `snapshot_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `snapshot_ref_digest`
- `recorded_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
