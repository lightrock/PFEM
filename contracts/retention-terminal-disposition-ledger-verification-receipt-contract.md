# Retention Terminal Disposition Ledger Verification Receipts Contract

A PFEM retention terminal disposition ledger verification receipts record should identify:

- `retention_terminal_disposition_ledger_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_disposition_ledger_record_id`
- `retention_terminal_rollup_report_closeout_record_id`
- `verification_state`
- `checked_terminal_disposition_ledger_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_disposition_ledger_ref_digest`
- `actual_terminal_disposition_ledger_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
