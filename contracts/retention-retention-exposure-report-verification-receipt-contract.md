# Retention Retention Exposure Report Verification Receipts Contract

A PFEM retention retention exposure report verification receipts record should identify:

- `retention_retention_exposure_report_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_retention_exposure_report_record_id`
- `retention_release_usage_summary_closeout_record_id`
- `verification_state`
- `checked_retention_exposure_report_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_retention_exposure_report_ref_digest`
- `actual_retention_exposure_report_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
