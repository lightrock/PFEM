# Retention Terminal Release Annex Records Contract

A PFEM retention terminal release annex records record should identify:

- `retention_terminal_release_annex_record_id`
- `terminal_release_annex_kind`
- `created_time`
- `node_id`
- `retention_terminal_archive_report_closeout_record_id`
- `retention_terminal_archive_report_verification_receipt_id`
- `terminal_release_annex_state`
- `terminal_release_annex_scope`
- `terminal_release_annex_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_release_annex_ref_digest`
- `terminal_release_annex_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
