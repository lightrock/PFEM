# Retention Deployment Release Verification Receipts Contract

A PFEM retention deployment release verification receipts record should identify:

- `retention_deployment_release_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_deployment_release_record_id`
- `retention_repository_release_closeout_record_id`
- `verification_state`
- `checked_deployment_release_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_deployment_release_ref_digest`
- `actual_deployment_release_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
