# Retention Terminal Public Index Records Contract

A PFEM retention terminal public index records record should identify:

- `retention_terminal_public_index_record_id`
- `terminal_public_index_kind`
- `created_time`
- `node_id`
- `retention_publication_closure_certificate_closeout_record_id`
- `retention_publication_closure_certificate_verification_receipt_id`
- `terminal_public_index_state`
- `terminal_public_index_scope`
- `terminal_public_index_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_public_index_ref_digest`
- `terminal_public_index_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
