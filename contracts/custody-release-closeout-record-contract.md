# Custody Release Closeout Records Contract

A PFEM custody release closeout records record should identify:

- `custody_release_closeout_record_id`
- `closeout_kind`
- `created_time`
- `node_id`
- `custody_release_verification_receipt_id`
- `custody_release_receipt_id`
- `custody_release_approval_id`
- `custody_release_request_id`
- `closeout_state`
- `outcome`
- `closed_refs`
- `basis_refs`
- `closed_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
