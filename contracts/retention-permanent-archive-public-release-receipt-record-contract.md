# Retention Permanent Archive Public Release Receipt Records Contract

A PFEM retention permanent archive public release receipt records record should identify:

- `retention_permanent_archive_public_release_receipt_record_id`
- `permanent_archive_public_release_receipt_kind`
- `created_time`
- `node_id`
- `retention_permanent_archive_public_release_notice_closeout_record_id`
- `retention_permanent_archive_public_release_notice_verification_receipt_id`
- `permanent_archive_public_release_receipt_state`
- `permanent_archive_public_release_receipt_scope`
- `permanent_archive_public_release_receipt_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `permanent_archive_public_release_receipt_ref_digest`
- `permanent_archive_public_release_receipt_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
