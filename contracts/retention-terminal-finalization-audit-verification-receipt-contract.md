# Retention Terminal Finalization Audit Verification Receipts Contract

A PFEM retention terminal finalization audit verification receipts record should identify:

- `retention_terminal_finalization_audit_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_finalization_audit_record_id`
- `retention_terminal_finalization_record_closeout_record_id`
- `verification_state`
- `checked_terminal_finalization_audit_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_finalization_audit_ref_digest`
- `actual_terminal_finalization_audit_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
