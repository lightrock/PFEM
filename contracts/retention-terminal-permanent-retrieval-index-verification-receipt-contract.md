# Retention Terminal Permanent Retrieval Index Verification Receipts Contract

A PFEM retention terminal permanent retrieval index verification receipts record should identify:

- `retention_terminal_permanent_retrieval_index_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_retrieval_index_record_id`
- `retention_terminal_permanent_storage_receipt_closeout_record_id`
- `verification_state`
- `checked_terminal_permanent_retrieval_index_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_permanent_retrieval_index_ref_digest`
- `actual_terminal_permanent_retrieval_index_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
