# Retention Terminal Permanent Archive Index Records Contract

A PFEM retention terminal permanent archive index records record should identify:

- `retention_terminal_permanent_archive_index_record_id`
- `terminal_permanent_archive_index_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_archive_package_closeout_record_id`
- `retention_terminal_permanent_archive_package_verification_receipt_id`
- `terminal_permanent_archive_index_state`
- `terminal_permanent_archive_index_scope`
- `terminal_permanent_archive_index_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_permanent_archive_index_ref_digest`
- `terminal_permanent_archive_index_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
