# Retention Terminal Storage Receipt Verification Receipts Contract

A PFEM retention terminal storage receipt verification receipts record should identify:

- `retention_terminal_storage_receipt_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_storage_receipt_record_id`
- `retention_terminal_archive_manifest_closeout_record_id`
- `verification_state`
- `checked_terminal_storage_receipt_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_storage_receipt_ref_digest`
- `actual_terminal_storage_receipt_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
