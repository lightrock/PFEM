# Retention Repository Release Records Contract

A PFEM retention repository release records record should identify:

- `retention_repository_release_record_id`
- `repository_release_kind`
- `created_time`
- `node_id`
- `retention_terminal_manifest_closeout_record_id`
- `retention_terminal_manifest_verification_receipt_id`
- `repository_release_state`
- `repository_release_scope`
- `repository_release_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `repository_release_ref_digest`
- `repository_release_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
