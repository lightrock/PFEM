# Retention Terminal Permanent Archive Package Verification Receipts Contract

A PFEM retention terminal permanent archive package verification receipts record should identify:

- `retention_terminal_permanent_archive_package_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_archive_package_record_id`
- `retention_terminal_archival_accession_closeout_record_id`
- `verification_state`
- `checked_terminal_permanent_archive_package_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_terminal_permanent_archive_package_ref_digest`
- `actual_terminal_permanent_archive_package_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
