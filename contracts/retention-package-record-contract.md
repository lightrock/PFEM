# Retention Package Records Contract

A PFEM retention package records record should identify:

- `retention_package_record_id`
- `package_kind`
- `created_time`
- `node_id`
- `retention_acceptance_closeout_record_id`
- `retention_acceptance_verification_receipt_id`
- `package_state`
- `package_scope`
- `package_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `package_ref_digest`
- `packaged_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
