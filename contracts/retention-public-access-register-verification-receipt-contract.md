# Retention Public Access Register Verification Receipts Contract

A PFEM retention public access register verification receipts record should identify:

- `retention_public_access_register_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_public_access_register_record_id`
- `retention_distribution_closure_notice_closeout_record_id`
- `verification_state`
- `checked_public_access_register_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_public_access_register_ref_digest`
- `actual_public_access_register_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
