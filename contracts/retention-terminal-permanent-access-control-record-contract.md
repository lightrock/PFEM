# Retention Terminal Permanent Access Control Records Contract

A PFEM retention terminal permanent access control records record should identify:

- `retention_terminal_permanent_access_control_record_id`
- `terminal_permanent_access_control_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_retrieval_index_closeout_record_id`
- `retention_terminal_permanent_retrieval_index_verification_receipt_id`
- `terminal_permanent_access_control_state`
- `terminal_permanent_access_control_scope`
- `terminal_permanent_access_control_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_permanent_access_control_ref_digest`
- `terminal_permanent_access_control_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
