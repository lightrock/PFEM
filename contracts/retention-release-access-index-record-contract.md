# Retention Release Access Index Records Contract

A PFEM retention release access index records record should identify:

- `retention_release_access_index_record_id`
- `release_access_index_kind`
- `created_time`
- `node_id`
- `retention_public_access_register_closeout_record_id`
- `retention_public_access_register_verification_receipt_id`
- `release_access_index_state`
- `release_access_index_scope`
- `release_access_index_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `release_access_index_ref_digest`
- `release_access_index_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
