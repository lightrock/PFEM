# Retention Terminal Permanent Storage Receipt Records Contract

A PFEM retention terminal permanent storage receipt records record should identify:

- `retention_terminal_permanent_storage_receipt_record_id`
- `terminal_permanent_storage_receipt_kind`
- `created_time`
- `node_id`
- `retention_terminal_permanent_storage_deposit_closeout_record_id`
- `retention_terminal_permanent_storage_deposit_verification_receipt_id`
- `terminal_permanent_storage_receipt_state`
- `terminal_permanent_storage_receipt_scope`
- `terminal_permanent_storage_receipt_refs`
- `subject_refs`
- `basis_refs`
- `digest_algorithm`
- `terminal_permanent_storage_receipt_ref_digest`
- `terminal_permanent_storage_receipt_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
