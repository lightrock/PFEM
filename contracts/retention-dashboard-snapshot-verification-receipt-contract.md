# Retention Dashboard Snapshot Verification Receipts Contract

A PFEM retention dashboard snapshot verification receipts record should identify:

- `retention_dashboard_snapshot_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_dashboard_snapshot_record_id`
- `retention_publication_closeout_record_id`
- `verification_state`
- `checked_dashboard_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_dashboard_ref_digest`
- `actual_dashboard_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
