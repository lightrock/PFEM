# Retention Distribution Package Verification Receipts Contract

A PFEM retention distribution package verification receipts record should identify:

- `retention_distribution_package_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_distribution_package_record_id`
- `retention_release_confirmation_closeout_record_id`
- `verification_state`
- `checked_distribution_package_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_distribution_package_ref_digest`
- `actual_distribution_package_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
