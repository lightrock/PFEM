# Retention Registry Verification Receipts Contract

A PFEM retention registry verification receipts record should identify:

- `retention_registry_verification_receipt_id`
- `receipt_kind`
- `created_time`
- `node_id`
- `retention_registry_record_id`
- `retention_certificate_closeout_record_id`
- `verification_state`
- `checked_registry_refs`
- `checked_subject_refs`
- `basis_refs`
- `digest_algorithm`
- `expected_registry_ref_digest`
- `actual_registry_ref_digest`
- `verified_by_ref`
- `summary`

This record keeps its boundary separate from the preceding PFEM artifact.
