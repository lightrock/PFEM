# Civil Dashboard Node Example

This example documents a dashboard-only PFEM shape.

Profile:

```text
profiles/civil-dashboard/civil-dashboard.profile.yaml
```

This profile receives federation input and supports dashboard review. It does
not assume local source adapters or local sensor control.

This is intentionally not a local-source example. It represents a node that
mostly receives summaries, requests more information, and helps humans decide
what to do next.
