# Retention Chain Verification Receipts

PFEM retention chain verification receipts add the next retention boundary.

The boundary is:

```text
retention chain record                = linked retention workflow summary
retention chain verification receipt  = evidence that retention-chain summary/digest was checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention chain record:
linked retention workflow summary

retention chain verification receipt:
evidence that retention-chain summary/digest was checked
```
