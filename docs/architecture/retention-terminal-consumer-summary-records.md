# Retention Terminal Consumer Summary Records

PFEM retention terminal consumer summary records add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal retrieval summary closeout record = formal closure of retention terminal retrieval summary workflow
retention terminal consumer summary record = terminal-consumer-summary layer terminal consumer summary record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal retrieval summary closeout record:
formal closure of retention terminal retrieval summary workflow

retention terminal consumer summary record:
terminal-consumer-summary layer terminal consumer summary record
```
