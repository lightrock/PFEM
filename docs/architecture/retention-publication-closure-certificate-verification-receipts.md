# Retention Publication Closure Certificate Verification Receipts

PFEM retention publication closure certificate verification receipts add the next retention publication closeout boundary.

The boundary is:

```text
retention publication closure certificate record = publication-closure-certificate layer publication closure certificate record
retention publication closure certificate verification receipt = evidence that publication closure certificate refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention publication closure certificate record:
publication-closure-certificate layer publication closure certificate record

retention publication closure certificate verification receipt:
evidence that publication closure certificate refs/digest were checked
```
