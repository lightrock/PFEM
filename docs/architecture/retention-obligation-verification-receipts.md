# Retention Obligation Verification Receipts

PFEM retention obligation verification receipts add the next retention boundary.

The boundary is:

```text
retention obligation record                = active retention obligation
retention obligation verification receipt  = evidence that retention obligation refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention obligation record:
active retention obligation

retention obligation verification receipt:
evidence that retention obligation refs/digest were checked
```
