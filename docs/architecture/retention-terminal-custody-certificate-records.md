# Retention Terminal Custody Certificate Records

PFEM retention terminal custody certificate records add the next terminal-status retention boundary.

The boundary is:

```text
retention terminal disposition ledger closeout record = formal closure of retention terminal disposition ledger workflow
retention terminal custody certificate record = terminal-custody-certificate layer terminal custody certificate record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal disposition ledger closeout record:
formal closure of retention terminal disposition ledger workflow

retention terminal custody certificate record:
terminal-custody-certificate layer terminal custody certificate record
```
