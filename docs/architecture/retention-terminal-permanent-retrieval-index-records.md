# Retention Terminal Permanent Retrieval Index Records

PFEM retention terminal permanent retrieval index records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent storage receipt closeout record = formal closure of retention terminal permanent storage receipt workflow
retention terminal permanent retrieval index record = terminal-permanent-retrieval-index layer terminal permanent retrieval index record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent storage receipt closeout record:
formal closure of retention terminal permanent storage receipt workflow

retention terminal permanent retrieval index record:
terminal-permanent-retrieval-index layer terminal permanent retrieval index record
```
