# Retention Terminal Public Digest Verification Receipts

PFEM retention terminal public digest verification receipts add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal public digest record = terminal-public-digest layer terminal public digest record
retention terminal public digest verification receipt = evidence that terminal public digest refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal public digest record:
terminal-public-digest layer terminal public digest record

retention terminal public digest verification receipt:
evidence that terminal public digest refs/digest were checked
```
