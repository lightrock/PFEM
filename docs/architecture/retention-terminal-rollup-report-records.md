# Retention Terminal Rollup Report Records

PFEM retention terminal rollup report records add the next terminal-status retention boundary.

The boundary is:

```text
retention terminal integrity certificate closeout record = formal closure of retention terminal integrity certificate workflow
retention terminal rollup report record = terminal-rollup-report layer terminal rollup report record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal integrity certificate closeout record:
formal closure of retention terminal integrity certificate workflow

retention terminal rollup report record:
terminal-rollup-report layer terminal rollup report record
```
