# Retention Terminal Permanent Fixity Register Records

PFEM retention terminal permanent fixity register records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent integrity receipt closeout record = formal closure of retention terminal permanent integrity receipt workflow
retention terminal permanent fixity register record = terminal-permanent-fixity-register layer terminal permanent fixity register record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent integrity receipt closeout record:
formal closure of retention terminal permanent integrity receipt workflow

retention terminal permanent fixity register record:
terminal-permanent-fixity-register layer terminal permanent fixity register record
```
