# Neutral Language

PFEM public documentation should describe deployment shapes, capabilities, trust boundaries, and evidence flows without naming specific customers, agencies, programs, or procurement targets.

Use neutral terms:

- field-radio-node
- community-mesh-node
- infrastructure-site-node
- civil-dashboard-node
- research-testbed-node
- formal-authority-rollup-node
- disconnected-edge-node
- regional-rollup-node

Avoid public-repo terms that imply a specific buyer, sponsor, agency, branch, or named deployment unless that reference is intentionally approved for release.

The architecture should stay reusable. Specific organizations belong in private configuration, private deployment notes, or customer-specific forks.
