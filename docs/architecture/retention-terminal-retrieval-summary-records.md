# Retention Terminal Retrieval Summary Records

PFEM retention terminal retrieval summary records add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal access summary closeout record = formal closure of retention terminal access summary workflow
retention terminal retrieval summary record = terminal-retrieval-summary layer terminal retrieval summary record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal access summary closeout record:
formal closure of retention terminal access summary workflow

retention terminal retrieval summary record:
terminal-retrieval-summary layer terminal retrieval summary record
```
