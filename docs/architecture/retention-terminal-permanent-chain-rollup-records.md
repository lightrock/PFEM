# Retention Terminal Permanent Chain Rollup Records

PFEM retention terminal permanent chain rollup records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent fixity register closeout record = formal closure of retention terminal permanent fixity register workflow
retention terminal permanent chain rollup record = terminal-permanent-chain-rollup layer terminal permanent chain rollup record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent fixity register closeout record:
formal closure of retention terminal permanent fixity register workflow

retention terminal permanent chain rollup record:
terminal-permanent-chain-rollup layer terminal permanent chain rollup record
```
