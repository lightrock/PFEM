# Retention Terminal Retrieval Certificate Records

PFEM retention terminal retrieval certificate records add the next terminal-status retention boundary.

The boundary is:

```text
retention terminal storage receipt closeout record = formal closure of retention terminal storage receipt workflow
retention terminal retrieval certificate record = terminal-retrieval-certificate layer terminal retrieval certificate record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal storage receipt closeout record:
formal closure of retention terminal storage receipt workflow

retention terminal retrieval certificate record:
terminal-retrieval-certificate layer terminal retrieval certificate record
```
