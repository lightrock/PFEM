# Retention Terminal Integrity Certificate Records

PFEM retention terminal integrity certificate records add the next terminal-status retention boundary.

The boundary is:

```text
retention terminal manifest attestation closeout record = formal closure of retention terminal manifest attestation workflow
retention terminal integrity certificate record = terminal-integrity-certificate layer terminal integrity certificate record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal manifest attestation closeout record:
formal closure of retention terminal manifest attestation workflow

retention terminal integrity certificate record:
terminal-integrity-certificate layer terminal integrity certificate record
```
