# Retention Access Publication Verification Receipts

PFEM retention access publication verification receipts add the next retention access/release boundary.

The boundary is:

```text
retention access publication record = distribution-layer access publication record
retention access publication verification receipt = evidence that access publication refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention access publication record:
distribution-layer access publication record

retention access publication verification receipt:
evidence that access publication refs/digest were checked
```
