# Retention Dashboard Snapshot Records

PFEM retention dashboard snapshot records add the next retention reporting/publication boundary.

The boundary is:

```text
retention publication closeout record = formal closure of publication workflow
retention dashboard snapshot record  = dashboard-ready snapshot of published retention status
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention publication closeout record:
formal closure of publication workflow

retention dashboard snapshot record:
dashboard-ready snapshot of published retention status
```
