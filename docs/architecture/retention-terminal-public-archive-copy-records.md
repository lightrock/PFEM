# Retention Terminal Public Archive Copy Records

PFEM retention terminal public archive copy records add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal public digest closeout record = formal closure of retention terminal public digest workflow
retention terminal public archive copy record = terminal-public-archive-copy layer terminal public archive copy record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal public digest closeout record:
formal closure of retention terminal public digest workflow

retention terminal public archive copy record:
terminal-public-archive-copy layer terminal public archive copy record
```
