# Retention Terminal Permanent Custody Transfer Verification Receipts

PFEM retention terminal permanent custody transfer verification receipts add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent custody transfer record = terminal-permanent-custody-transfer layer terminal permanent custody transfer record
retention terminal permanent custody transfer verification receipt = evidence that terminal permanent custody transfer refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.
