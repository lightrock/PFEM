# Retention Distribution Closure Notice Records

PFEM retention distribution closure notice records add the next retention post-access boundary.

The boundary is:

```text
retention publication certificate closeout record = formal closure of retention publication certificate workflow
retention distribution closure notice record = distribution-closure-notice layer distribution closure notice record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention publication certificate closeout record:
formal closure of retention publication certificate workflow

retention distribution closure notice record:
distribution-closure-notice layer distribution closure notice record
```
