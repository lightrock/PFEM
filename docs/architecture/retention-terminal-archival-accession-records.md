# Retention Terminal Archival Accession Records

PFEM retention terminal archival accession records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal finalization audit closeout record = formal closure of retention terminal finalization audit workflow
retention terminal archival accession record = terminal-archival-accession layer terminal archival accession record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal finalization audit closeout record:
formal closure of retention terminal finalization audit workflow

retention terminal archival accession record:
terminal-archival-accession layer terminal archival accession record
```
