# Custody Release Closeout Records

PFEM custody release closeout records add the next custody boundary.

The boundary is:

```text
custody release verification receipt = evidence that released refs were checked
custody release closeout record      = final closure of the release workflow
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody release verification receipt:
evidence that released refs were checked

custody release closeout record:
final closure of the release workflow
```
