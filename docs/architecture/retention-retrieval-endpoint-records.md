# Retention Retrieval Endpoint Records

PFEM retention retrieval endpoint records add the next retention access/release boundary.

The boundary is:

```text
retention retrieval catalog closeout record = formal closure of retention retrieval catalog workflow
retention retrieval endpoint record = retrieval-endpoint layer retrieval endpoint record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention retrieval catalog closeout record:
formal closure of retention retrieval catalog workflow

retention retrieval endpoint record:
retrieval-endpoint layer retrieval endpoint record
```
