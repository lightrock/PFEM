# Retention Permanent Archive Terminal Closure Record Records

PFEM retention permanent archive terminal closure record records add the next permanent-archive terminal authority boundary.

The boundary is:

```text
retention permanent archive terminal final distribution summary closeout record = formal closure of retention permanent archive terminal final distribution summary workflow
retention permanent archive terminal closure record record = permanent-archive-terminal-closure-record layer permanent archive terminal closure record record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.
