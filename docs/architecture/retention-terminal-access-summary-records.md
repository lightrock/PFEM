# Retention Terminal Access Summary Records

PFEM retention terminal access summary records add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal distribution summary closeout record = formal closure of retention terminal distribution summary workflow
retention terminal access summary record = terminal-access-summary layer terminal access summary record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal distribution summary closeout record:
formal closure of retention terminal distribution summary workflow

retention terminal access summary record:
terminal-access-summary layer terminal access summary record
```
