# Retention Certificate Records

PFEM retention certificate records add the next retention closure boundary.

The boundary is:

```text
retention terminal status closeout record = formal closure of terminal status workflow
retention certificate record              = certificate issued for closed terminal retention status
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal status closeout record:
formal closure of terminal status workflow

retention certificate record:
certificate issued for closed terminal retention status
```
