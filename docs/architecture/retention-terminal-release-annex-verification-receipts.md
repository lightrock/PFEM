# Retention Terminal Release Annex Verification Receipts

PFEM retention terminal release annex verification receipts add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal release annex record = terminal-release-annex layer terminal release annex record
retention terminal release annex verification receipt = evidence that terminal release annex refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal release annex record:
terminal-release-annex layer terminal release annex record

retention terminal release annex verification receipt:
evidence that terminal release annex refs/digest were checked
```
