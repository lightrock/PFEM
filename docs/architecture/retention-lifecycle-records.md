# Retention Lifecycle Records

PFEM retention lifecycle records add the next retention boundary.

The boundary is:

```text
retention chain verification receipt = evidence that retention-chain summary/digest was checked
retention lifecycle record           = lifecycle summary of the retention review/decision/action chain
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention chain verification receipt:
evidence that retention-chain summary/digest was checked

retention lifecycle record:
lifecycle summary of the retention review/decision/action chain
```
