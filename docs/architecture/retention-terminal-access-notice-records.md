# Retention Terminal Access Notice Records

PFEM retention terminal access notice records add the next retention access/release boundary.

The boundary is:

```text
retention final release bundle closeout record = formal closure of retention final release bundle workflow
retention terminal access notice record = terminal-access-notice layer terminal access notice record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention final release bundle closeout record:
formal closure of retention final release bundle workflow

retention terminal access notice record:
terminal-access-notice layer terminal access notice record
```
