# Retention Public Access Register Records

PFEM retention public access register records add the next retention post-access boundary.

The boundary is:

```text
retention distribution closure notice closeout record = formal closure of retention distribution closure notice workflow
retention public access register record = public-access-register layer public access register record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention distribution closure notice closeout record:
formal closure of retention distribution closure notice workflow

retention public access register record:
public-access-register layer public access register record
```
