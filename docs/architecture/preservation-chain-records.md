# Preservation Chain Records

PFEM preservation chain records add the next preservation/retention boundary.

The boundary is:

```text
preservation closeout record = closure of a preservation verification cycle
preservation chain record    = linked summary of preservation/verification/closeout
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
preservation closeout record:
closure of a preservation verification cycle

preservation chain record:
linked summary of preservation/verification/closeout
```
