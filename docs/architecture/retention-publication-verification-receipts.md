# Retention Publication Verification Receipts

PFEM retention publication verification receipts add the next retention reporting/publication boundary.

The boundary is:

```text
retention publication record                = publication event for verified retention report
retention publication verification receipt  = evidence that publication refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention publication record:
publication event for verified retention report

retention publication verification receipt:
evidence that publication refs/digest were checked
```
