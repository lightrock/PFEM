# Archive Receipts

PFEM archive receipts add the next lifecycle/archive boundary.

The boundary is:

```text
archive manifest record = manifest of lifecycle artifacts prepared for archive
archive receipt         = evidence that archive action actually happened
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
archive manifest record:
manifest of lifecycle artifacts prepared for archive

archive receipt:
evidence that archive action actually happened
```
