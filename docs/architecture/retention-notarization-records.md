# Retention Notarization Records

PFEM retention notarization records add the next retention endcap boundary.

The boundary is:

```text
retention seal closeout record = formal closure of retention seal workflow
retention notarization record = post-closure notarization record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention seal closeout record:
formal closure of retention seal workflow

retention notarization record:
post-closure notarization record
```
