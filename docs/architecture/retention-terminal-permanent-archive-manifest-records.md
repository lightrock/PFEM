# Retention Terminal Permanent Archive Manifest Records

PFEM retention terminal permanent archive manifest records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent archive index closeout record = formal closure of retention terminal permanent archive index workflow
retention terminal permanent archive manifest record = terminal-permanent-archive-manifest layer terminal permanent archive manifest record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent archive index closeout record:
formal closure of retention terminal permanent archive index workflow

retention terminal permanent archive manifest record:
terminal-permanent-archive-manifest layer terminal permanent archive manifest record
```
