# Custody Lifecycle Closeout Records

PFEM custody lifecycle closeout records add the next lifecycle/archive boundary.

The boundary is:

```text
custody lifecycle verification receipt = evidence that lifecycle summary/digest was checked
custody lifecycle closeout record      = final closure of the custody lifecycle
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody lifecycle verification receipt:
evidence that lifecycle summary/digest was checked

custody lifecycle closeout record:
final closure of the custody lifecycle
```
