# Retention Terminal Permanent Access Control Verification Receipts

PFEM retention terminal permanent access control verification receipts add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent access control record = terminal-permanent-access-control layer terminal permanent access control record
retention terminal permanent access control verification receipt = evidence that terminal permanent access control refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent access control record:
terminal-permanent-access-control layer terminal permanent access control record

retention terminal permanent access control verification receipt:
evidence that terminal permanent access control refs/digest were checked
```
