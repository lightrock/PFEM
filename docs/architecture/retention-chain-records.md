# Retention Chain Records

PFEM retention chain records add the next retention boundary.

The boundary is:

```text
retention action closeout record = formal closure of the retention action workflow
retention chain record          = linked summary of review/decision/approval/action/closeout
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention action closeout record:
formal closure of the retention action workflow

retention chain record:
linked summary of review/decision/approval/action/closeout
```
