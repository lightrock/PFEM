# Retention Final Publication Notice Records

PFEM retention final publication notice records add the next retention post-access boundary.

The boundary is:

```text
retention release terminal report closeout record = formal closure of retention release terminal report workflow
retention final publication notice record = final-publication-notice layer final publication notice record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention release terminal report closeout record:
formal closure of retention release terminal report workflow

retention final publication notice record:
final-publication-notice layer final publication notice record
```
