# Retention Access Publication Records

PFEM retention access publication records add the next retention distribution boundary.

The boundary is:

```text
retention distribution manifest closeout record = formal closure of retention distribution manifest workflow
retention access publication record = distribution-layer access publication record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention distribution manifest closeout record:
formal closure of retention distribution manifest workflow

retention access publication record:
distribution-layer access publication record
```
