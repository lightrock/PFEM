# Custody Release Receipts

PFEM custody release receipts add the next custody boundary.

The boundary is:

```text
custody release approval = authorization to execute release
custody release receipt  = evidence that release actually happened
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody release approval:
authorization to execute release

custody release receipt:
evidence that release actually happened
```
