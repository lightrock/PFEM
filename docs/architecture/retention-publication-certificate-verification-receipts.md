# Retention Publication Certificate Verification Receipts

PFEM retention publication certificate verification receipts add the next retention post-access boundary.

The boundary is:

```text
retention publication certificate record = publication-certificate layer publication certificate record
retention publication certificate verification receipt = evidence that publication certificate refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention publication certificate record:
publication-certificate layer publication certificate record

retention publication certificate verification receipt:
evidence that publication certificate refs/digest were checked
```
