# Retention Retrieval Token Records

PFEM retention retrieval token records add the next retention access/release boundary.

The boundary is:

```text
retention retrieval endpoint closeout record = formal closure of retention retrieval endpoint workflow
retention retrieval token record = retrieval-token layer retrieval token record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention retrieval endpoint closeout record:
formal closure of retention retrieval endpoint workflow

retention retrieval token record:
retrieval-token layer retrieval token record
```
