# Retention Permanent Archive Terminal Closeout Digest Records

PFEM retention permanent archive terminal closeout digest records add the next permanent-archive terminal closeout boundary.

The boundary is:

```text
retention permanent archive terminal closeout index closeout record = formal closure of retention permanent archive terminal closeout index workflow
retention permanent archive terminal closeout digest record = permanent-archive-terminal-closeout-digest layer permanent archive terminal closeout digest record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.
