# Retention Retention Exposure Report Records

PFEM retention retention exposure report records add the next retention access/release boundary.

The boundary is:

```text
retention release usage summary closeout record = formal closure of retention release usage summary workflow
retention retention exposure report record = retention-exposure layer retention exposure report record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention release usage summary closeout record:
formal closure of retention release usage summary workflow

retention retention exposure report record:
retention-exposure layer retention exposure report record
```
