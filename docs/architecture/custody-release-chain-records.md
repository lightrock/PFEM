# Custody Release Chain Records

PFEM custody release chain records add the next custody boundary.

The boundary is:

```text
custody release closeout record = final closure of the release workflow
custody release chain record    = linked summary of the closed release workflow
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody release closeout record:
final closure of the release workflow

custody release chain record:
linked summary of the closed release workflow
```
