# Archive Lifecycle Records

PFEM archive lifecycle records add the next archive/preservation boundary.

The boundary is:

```text
archive index closeout record = formal closure of the archive index workflow
archive lifecycle record      = summary of archive manifest/receipt/verification/chain/index
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
archive index closeout record:
formal closure of the archive index workflow

archive lifecycle record:
summary of archive manifest/receipt/verification/chain/index
```
