# Retention Terminal Public Digest Records

PFEM retention terminal public digest records add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal public index closeout record = formal closure of retention terminal public index workflow
retention terminal public digest record = terminal-public-digest layer terminal public digest record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal public index closeout record:
formal closure of retention terminal public index workflow

retention terminal public digest record:
terminal-public-digest layer terminal public digest record
```
