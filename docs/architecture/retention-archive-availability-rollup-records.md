# Retention Archive Availability Rollup Records

PFEM retention archive availability rollup records add the next retention post-access boundary.

The boundary is:

```text
retention release access closeout summary closeout record = formal closure of retention release access closeout summary workflow
retention archive availability rollup record = archive-availability-rollup layer archive availability rollup record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention release access closeout summary closeout record:
formal closure of retention release access closeout summary workflow

retention archive availability rollup record:
archive-availability-rollup layer archive availability rollup record
```
