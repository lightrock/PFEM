# Custody Release Requests

PFEM custody release requests add the next custody boundary.

The boundary is:

```text
custody ledger verification receipt = evidence that ledger entry was checked
custody release request             = request to release artifacts from active custody handling
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody ledger verification receipt:
evidence that ledger entry was checked

custody release request:
request to release artifacts from active custody handling
```
