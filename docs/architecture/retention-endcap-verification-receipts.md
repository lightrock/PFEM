# Retention Endcap Verification Receipts

PFEM retention endcap verification receipts add the next retention endcap boundary.

The boundary is:

```text
retention endcap record = post-closure endcap record
retention endcap verification receipt = evidence that endcap refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention endcap record:
post-closure endcap record

retention endcap verification receipt:
evidence that endcap refs/digest were checked
```
