# Retention Terminal Archival Accession Verification Receipts

PFEM retention terminal archival accession verification receipts add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal archival accession record = terminal-archival-accession layer terminal archival accession record
retention terminal archival accession verification receipt = evidence that terminal archival accession refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal archival accession record:
terminal-archival-accession layer terminal archival accession record

retention terminal archival accession verification receipt:
evidence that terminal archival accession refs/digest were checked
```
