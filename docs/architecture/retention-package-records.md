# Retention Package Records

PFEM retention package records add the next retention finalization boundary.

The boundary is:

```text
retention acceptance closeout record = formal closure of retention acceptance workflow
retention package record             = packaged retention acceptance for finalization
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention acceptance closeout record:
formal closure of retention acceptance workflow

retention package record:
packaged retention acceptance for finalization
```
