# Retention Terminal Publication Bundle Records

PFEM retention terminal publication bundle records add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal release annex closeout record = formal closure of retention terminal release annex workflow
retention terminal publication bundle record = terminal-publication-bundle layer terminal publication bundle record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal release annex closeout record:
formal closure of retention terminal release annex workflow

retention terminal publication bundle record:
terminal-publication-bundle layer terminal publication bundle record
```
