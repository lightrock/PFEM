# Capability Model

PFEM is composed from capabilities. A node profile enables, disables, or configures capabilities.

Capabilities are not products. They are reusable behaviors.

Examples:

- source input
- manual report intake
- normalized observation handling
- local memory
- local decision support
- dashboard view
- federation input
- federation output
- rollup summary production
- evidence package production
- replay and simulation
- health reporting

A deployment shape is created by combining capabilities with adapters, schemas, policies, and operator flows.

## Rule

Do not fork the architecture for each deployment shape. Add or configure capabilities instead.
