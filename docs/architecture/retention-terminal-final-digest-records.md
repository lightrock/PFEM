# Retention Terminal Final Digest Records

PFEM retention terminal final digest records add the next terminal-status retention boundary.

The boundary is:

```text
retention terminal compliance report closeout record = formal closure of retention terminal compliance report workflow
retention terminal final digest record = terminal-final-digest layer terminal final digest record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal compliance report closeout record:
formal closure of retention terminal compliance report workflow

retention terminal final digest record:
terminal-final-digest layer terminal final digest record
```
