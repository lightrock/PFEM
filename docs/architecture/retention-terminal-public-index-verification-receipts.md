# Retention Terminal Public Index Verification Receipts

PFEM retention terminal public index verification receipts add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal public index record = terminal-public-index layer terminal public index record
retention terminal public index verification receipt = evidence that terminal public index refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal public index record:
terminal-public-index layer terminal public index record

retention terminal public index verification receipt:
evidence that terminal public index refs/digest were checked
```
