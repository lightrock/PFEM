# Retention Retrieval Catalog Records

PFEM retention retrieval catalog records add the next retention access/release boundary.

The boundary is:

```text
retention access ledger closeout record = formal closure of retention access ledger workflow
retention retrieval catalog record = retrieval-catalog layer retrieval catalog record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention access ledger closeout record:
formal closure of retention access ledger workflow

retention retrieval catalog record:
retrieval-catalog layer retrieval catalog record
```
