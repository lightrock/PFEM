# Retention Terminal Compliance Report Records

PFEM retention terminal compliance report records add the next terminal-status retention boundary.

The boundary is:

```text
retention terminal control snapshot closeout record = formal closure of retention terminal control snapshot workflow
retention terminal compliance report record = terminal-compliance-report layer terminal compliance report record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal control snapshot closeout record:
formal closure of retention terminal control snapshot workflow

retention terminal compliance report record:
terminal-compliance-report layer terminal compliance report record
```
