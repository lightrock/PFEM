# Retention Terminal Archive Manifest Records

PFEM retention terminal archive manifest records add the next terminal-status retention boundary.

The boundary is:

```text
retention terminal custody certificate closeout record = formal closure of retention terminal custody certificate workflow
retention terminal archive manifest record = terminal-archive-manifest layer terminal archive manifest record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal custody certificate closeout record:
formal closure of retention terminal custody certificate workflow

retention terminal archive manifest record:
terminal-archive-manifest layer terminal archive manifest record
```
