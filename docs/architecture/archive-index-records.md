# Archive Index Records

PFEM archive index records add the next archive boundary.

The boundary is:

```text
archive chain verification receipt = evidence that archive-chain summary/digest was checked
archive index record              = lookup/index entry for the verified archive chain
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
archive chain verification receipt:
evidence that archive-chain summary/digest was checked

archive index record:
lookup/index entry for the verified archive chain
```
