# Retention Permanent Archive Exception Register Records

PFEM retention permanent archive exception register records add the next permanent-archive continuation boundary.

The boundary is:

```text
retention permanent archive schedule snapshot closeout record = formal closure of retention permanent archive schedule snapshot workflow
retention permanent archive exception register record = permanent-archive-exception-register layer permanent archive exception register record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention permanent archive schedule snapshot closeout record:
formal closure of retention permanent archive schedule snapshot workflow

retention permanent archive exception register record:
permanent-archive-exception-register layer permanent archive exception register record
```
