# Retention Permanent Archive Exception Summary Records

PFEM retention permanent archive exception summary records add the next permanent-archive continuation boundary.

The boundary is:

```text
retention permanent archive exception register closeout record = formal closure of retention permanent archive exception register workflow
retention permanent archive exception summary record = permanent-archive-exception-summary layer permanent archive exception summary record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention permanent archive exception register closeout record:
formal closure of retention permanent archive exception register workflow

retention permanent archive exception summary record:
permanent-archive-exception-summary layer permanent archive exception summary record
```
