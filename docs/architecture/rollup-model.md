# Rollup Model

A rollup is a derived summary created for another node, dashboard, review layer, or coordination layer.

Rollups are useful because not every participant needs all raw local records.

A rollup may include:

- scope
- time window
- subject references
- count summaries
- status summaries
- confidence notes
- completeness notes
- lineage references
- sharing scope

## Rules

- A rollup is not raw local truth.
- A rollup should say what it summarizes.
- A rollup should say what it does not include when that matters.
- A rollup should preserve source lineage references where practical.
- A rollup should not silently upgrade uncertainty into certainty.
