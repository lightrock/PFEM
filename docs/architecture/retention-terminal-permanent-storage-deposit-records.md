# Retention Terminal Permanent Storage Deposit Records

PFEM retention terminal permanent storage deposit records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent archive manifest closeout record = formal closure of retention terminal permanent archive manifest workflow
retention terminal permanent storage deposit record = terminal-permanent-storage-deposit layer terminal permanent storage deposit record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent archive manifest closeout record:
formal closure of retention terminal permanent archive manifest workflow

retention terminal permanent storage deposit record:
terminal-permanent-storage-deposit layer terminal permanent storage deposit record
```
