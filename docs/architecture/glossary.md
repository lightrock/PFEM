# PFEM Glossary

## Adapter

A component that translates source-specific input into PFEM contracts.

## Capability

A reusable behavior that a node profile may enable or disable.

## Dashboard action

A human-facing recommended next step or workflow item.

## Evidence

A source record or preserved source material with provenance metadata.

## Finding

An interpreted result derived from evidence, observations, context, or rules.

## Federation message

An attributable message exchanged between PFEM nodes.

## Node profile

Configuration describing a deployment shape.

## Normalized observation

A structured observation derived from one or more evidence records.

## Rollup summary

A derived summary intended for another node, dashboard, or review layer.

## Source

The origin of incoming evidence or observations.
