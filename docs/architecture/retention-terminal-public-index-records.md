# Retention Terminal Public Index Records

PFEM retention terminal public index records add the next retention publication closeout boundary.

The boundary is:

```text
retention publication closure certificate closeout record = formal closure of retention publication closure certificate workflow
retention terminal public index record = terminal-public-index layer terminal public index record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention publication closure certificate closeout record:
formal closure of retention publication closure certificate workflow

retention terminal public index record:
terminal-public-index layer terminal public index record
```
