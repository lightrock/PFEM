# Custody Release Verification Receipts

PFEM custody release verification receipts add the next custody boundary.

The boundary is:

```text
custody release receipt               = evidence that release actually happened
custody release verification receipt  = evidence that released refs were checked afterward
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody release receipt:
evidence that release actually happened

custody release verification receipt:
evidence that released refs were checked afterward
```
