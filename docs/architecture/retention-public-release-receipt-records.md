# Retention Public Release Receipt Records

PFEM retention public release receipt records add the next retention post-access boundary.

The boundary is:

```text
retention consumer availability notice closeout record = formal closure of retention consumer availability notice workflow
retention public release receipt record = public-release-receipt layer public release receipt record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention consumer availability notice closeout record:
formal closure of retention consumer availability notice workflow

retention public release receipt record:
public-release-receipt layer public release receipt record
```
