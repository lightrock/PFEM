# Retention Terminal Manifest Records

PFEM retention terminal manifest records add the next retention release boundary.

The boundary is:

```text
retention master ledger closeout record = formal closure of retention master ledger workflow
retention terminal manifest record = release-layer terminal manifest record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention master ledger closeout record:
formal closure of retention master ledger workflow

retention terminal manifest record:
release-layer terminal manifest record
```
