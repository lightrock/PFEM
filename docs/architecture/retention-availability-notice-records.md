# Retention Availability Notice Records

PFEM retention availability notice records add the next retention release-continuation boundary.

The boundary is:

```text
retention deployment release closeout record = formal closure of retention deployment release workflow
retention availability notice record = release-continuation availability notice record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention deployment release closeout record:
formal closure of retention deployment release workflow

retention availability notice record:
release-continuation availability notice record
```
