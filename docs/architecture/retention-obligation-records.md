# Retention Obligation Records

PFEM retention obligation records add the next retention boundary.

The boundary is:

```text
retention policy compliance verification receipt = evidence that compliance result was checked
retention obligation record                      = active obligation created by retention policy/state
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention policy compliance verification receipt:
evidence that compliance result was checked

retention obligation record:
active obligation created by retention policy/state
```
