# Custody Lifecycle Records

PFEM custody lifecycle records add the next custody boundary.

The boundary is:

```text
custody release chain verification receipt = evidence that release-chain summary/digest was checked
custody lifecycle record                    = summary of custody, ledger, and release chains
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody release chain verification receipt:
evidence that release-chain summary/digest was checked

custody lifecycle record:
summary of custody, ledger, and release chains
```
