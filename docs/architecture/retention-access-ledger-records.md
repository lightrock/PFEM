# Retention Access Ledger Records

PFEM retention access ledger records add the next retention access/release boundary.

The boundary is:

```text
retention access grant closeout record = formal closure of retention access grant workflow
retention access ledger record = access-ledger layer access ledger record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention access grant closeout record:
formal closure of retention access grant workflow

retention access ledger record:
access-ledger layer access ledger record
```
