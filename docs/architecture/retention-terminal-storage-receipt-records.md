# Retention Terminal Storage Receipt Records

PFEM retention terminal storage receipt records add the next terminal-status retention boundary.

The boundary is:

```text
retention terminal archive manifest closeout record = formal closure of retention terminal archive manifest workflow
retention terminal storage receipt record = terminal-storage-receipt layer terminal storage receipt record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal archive manifest closeout record:
formal closure of retention terminal archive manifest workflow

retention terminal storage receipt record:
terminal-storage-receipt layer terminal storage receipt record
```
