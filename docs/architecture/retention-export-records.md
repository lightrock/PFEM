# Retention Export Records

PFEM retention export records add the next retention handoff/export boundary.

The boundary is:

```text
retention summary closeout record = formal closure of retention summary workflow
retention export record           = export event for closed retention summary
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention summary closeout record:
formal closure of retention summary workflow

retention export record:
export event for closed retention summary
```
