# Archive Lifecycle Verification Receipts

PFEM archive lifecycle verification receipts add the next archive/preservation boundary.

The boundary is:

```text
archive lifecycle record                = summary of the archive workflow lifecycle
archive lifecycle verification receipt  = evidence that archive lifecycle summary/digest was checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
archive lifecycle record:
summary of the archive workflow lifecycle

archive lifecycle verification receipt:
evidence that archive lifecycle summary/digest was checked
```
