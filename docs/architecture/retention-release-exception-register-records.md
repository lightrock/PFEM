# Retention Release Exception Register Records

PFEM retention release exception register records add the next retention post-access boundary.

The boundary is:

```text
retention public release receipt closeout record = formal closure of retention public release receipt workflow
retention release exception register record = release-exception-register layer release exception register record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention public release receipt closeout record:
formal closure of retention public release receipt workflow

retention release exception register record:
release-exception-register layer release exception register record
```
