# Retention Consumer Receipt Records

PFEM retention consumer receipt records add the next retention access/release boundary.

The boundary is:

```text
retention retrieval token closeout record = formal closure of retention retrieval token workflow
retention consumer receipt record = consumer-receipt layer consumer receipt record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention retrieval token closeout record:
formal closure of retention retrieval token workflow

retention consumer receipt record:
consumer-receipt layer consumer receipt record
```
