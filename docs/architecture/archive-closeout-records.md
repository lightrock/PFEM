# Archive Closeout Records

PFEM archive closeout records add the next archive boundary.

The boundary is:

```text
archive verification receipt = evidence that archived refs/location were checked
archive closeout record      = formal closure of the archive workflow
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
archive verification receipt:
evidence that archived refs/location were checked

archive closeout record:
formal closure of the archive workflow
```
