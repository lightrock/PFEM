# Retention Terminal Archive Report Records

PFEM retention terminal archive report records add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal exception summary closeout record = formal closure of retention terminal exception summary workflow
retention terminal archive report record = terminal-archive-report layer terminal archive report record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal exception summary closeout record:
formal closure of retention terminal exception summary workflow

retention terminal archive report record:
terminal-archive-report layer terminal archive report record
```
