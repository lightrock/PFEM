# Preservation Verification Receipts

PFEM preservation verification receipts add the next preservation/retention boundary.

The boundary is:

```text
preservation record                = ongoing preservation state for archived artifacts
preservation verification receipt  = evidence that preserved refs/state were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
preservation record:
ongoing preservation state for archived artifacts

preservation verification receipt:
evidence that preserved refs/state were checked
```
