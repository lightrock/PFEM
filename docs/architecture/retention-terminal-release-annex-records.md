# Retention Terminal Release Annex Records

PFEM retention terminal release annex records add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal archive report closeout record = formal closure of retention terminal archive report workflow
retention terminal release annex record = terminal-release-annex layer terminal release annex record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal archive report closeout record:
formal closure of retention terminal archive report workflow

retention terminal release annex record:
terminal-release-annex layer terminal release annex record
```
