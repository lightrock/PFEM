# Archive Chain Verification Receipts

PFEM archive chain verification receipts add the next archive boundary.

The boundary is:

```text
archive chain record                = linked archive workflow summary
archive chain verification receipt  = evidence that archive-chain summary/digest was checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
archive chain record:
linked archive workflow summary

archive chain verification receipt:
evidence that archive-chain summary/digest was checked
```
