# Custody Lifecycle Verification Receipts

PFEM custody lifecycle verification receipts add the next lifecycle/archive boundary.

The boundary is:

```text
custody lifecycle record                = summary of custody, ledger, and release chains
custody lifecycle verification receipt  = evidence that lifecycle summary/digest was checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody lifecycle record:
summary of custody, ledger, and release chains

custody lifecycle verification receipt:
evidence that lifecycle summary/digest was checked
```
