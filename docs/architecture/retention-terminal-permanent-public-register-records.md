# Retention Terminal Permanent Public Register Records

PFEM retention terminal permanent public register records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent custody transfer closeout record = formal closure of retention terminal permanent custody transfer workflow
retention terminal permanent public register record = terminal-permanent-public-register layer terminal permanent public register record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent custody transfer closeout record:
formal closure of retention terminal permanent custody transfer workflow

retention terminal permanent public register record:
terminal-permanent-public-register layer terminal permanent public register record
```
