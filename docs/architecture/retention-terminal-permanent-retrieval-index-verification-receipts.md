# Retention Terminal Permanent Retrieval Index Verification Receipts

PFEM retention terminal permanent retrieval index verification receipts add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent retrieval index record = terminal-permanent-retrieval-index layer terminal permanent retrieval index record
retention terminal permanent retrieval index verification receipt = evidence that terminal permanent retrieval index refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent retrieval index record:
terminal-permanent-retrieval-index layer terminal permanent retrieval index record

retention terminal permanent retrieval index verification receipt:
evidence that terminal permanent retrieval index refs/digest were checked
```
