# Retention Publication Records

PFEM retention publication records add the next retention reporting/publication boundary.

The boundary is:

```text
retention report closeout record = formal closure of the verified retention report
retention publication record     = publication event for that verified retention report
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention report closeout record:
formal closure of the verified retention report

retention publication record:
publication event for that verified retention report
```
