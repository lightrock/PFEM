# Retention Permanent Archive Handoff Package Records

PFEM retention permanent archive handoff package records add the next permanent-archive continuation boundary.

The boundary is:

```text
retention permanent archive accession summary closeout record = formal closure of retention permanent archive accession summary workflow
retention permanent archive handoff package record = permanent-archive-handoff-package layer permanent archive handoff package record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention permanent archive accession summary closeout record:
formal closure of retention permanent archive accession summary workflow

retention permanent archive handoff package record:
permanent-archive-handoff-package layer permanent archive handoff package record
```
