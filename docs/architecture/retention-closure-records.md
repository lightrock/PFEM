# Retention Closure Records

PFEM retention closure records add the next retention closure boundary.

The boundary is:

```text
retention registry closeout record = formal closure of registry workflow
retention closure record           = closure record for the registered retention certificate path
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention registry closeout record:
formal closure of registry workflow

retention closure record:
closure record for the registered retention certificate path
```
