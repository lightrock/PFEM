# Retention Rollup Closeout Records

PFEM retention rollup closeout records add the next retention reporting/publication boundary.

The boundary is:

```text
retention rollup verification receipt = evidence that rollup refs/digest were checked
retention rollup closeout record      = formal closure of the retention rollup workflow
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention rollup verification receipt:
evidence that rollup refs/digest were checked

retention rollup closeout record:
formal closure of the retention rollup workflow
```
