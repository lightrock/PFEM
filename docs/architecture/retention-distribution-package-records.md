# Retention Distribution Package Records

PFEM retention distribution package records add the next retention distribution boundary.

The boundary is:

```text
retention release confirmation closeout record = formal closure of retention release confirmation workflow
retention distribution package record = distribution-layer distribution package record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention release confirmation closeout record:
formal closure of retention release confirmation workflow

retention distribution package record:
distribution-layer distribution package record
```
