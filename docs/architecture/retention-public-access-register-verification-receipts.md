# Retention Public Access Register Verification Receipts

PFEM retention public access register verification receipts add the next retention post-access boundary.

The boundary is:

```text
retention public access register record = public-access-register layer public access register record
retention public access register verification receipt = evidence that public access register refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention public access register record:
public-access-register layer public access register record

retention public access register verification receipt:
evidence that public access register refs/digest were checked
```
