# Retention Release Terminal Report Records

PFEM retention release terminal report records add the next retention post-access boundary.

The boundary is:

```text
retention release metrics snapshot closeout record = formal closure of retention release metrics snapshot workflow
retention release terminal report record = release-terminal-report layer release terminal report record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention release metrics snapshot closeout record:
formal closure of retention release metrics snapshot workflow

retention release terminal report record:
release-terminal-report layer release terminal report record
```
