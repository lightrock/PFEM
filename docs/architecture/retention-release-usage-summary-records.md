# Retention Release Usage Summary Records

PFEM retention release usage summary records add the next retention access/release boundary.

The boundary is:

```text
retention release health snapshot closeout record = formal closure of retention release health snapshot workflow
retention release usage summary record = release-usage layer release usage summary record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention release health snapshot closeout record:
formal closure of retention release health snapshot workflow

retention release usage summary record:
release-usage layer release usage summary record
```
