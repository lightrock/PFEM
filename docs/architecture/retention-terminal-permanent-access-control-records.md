# Retention Terminal Permanent Access Control Records

PFEM retention terminal permanent access control records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent retrieval index closeout record = formal closure of retention terminal permanent retrieval index workflow
retention terminal permanent access control record = terminal-permanent-access-control layer terminal permanent access control record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent retrieval index closeout record:
formal closure of retention terminal permanent retrieval index workflow

retention terminal permanent access control record:
terminal-permanent-access-control layer terminal permanent access control record
```
