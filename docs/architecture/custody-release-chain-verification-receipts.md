# Custody Release Chain Verification Receipts

PFEM custody release chain verification receipts add the next custody boundary.

The boundary is:

```text
custody release chain record                = linked summary of the closed release workflow
custody release chain verification receipt  = evidence that release-chain summary/digest was checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody release chain record:
linked summary of the closed release workflow

custody release chain verification receipt:
evidence that release-chain summary/digest was checked
```
