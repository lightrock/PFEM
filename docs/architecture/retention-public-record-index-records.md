# Retention Public Record Index Records

PFEM retention public record index records add the next retention access/release boundary.

The boundary is:

```text
retention release closeout summary closeout record = formal closure of retention release closeout summary workflow
retention public record index record = public-record-index layer public record index record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention release closeout summary closeout record:
formal closure of retention release closeout summary workflow

retention public record index record:
public-record-index layer public record index record
```
