# Retention Distribution Manifest Records

PFEM retention distribution manifest records add the next retention distribution boundary.

The boundary is:

```text
retention distribution package closeout record = formal closure of retention distribution package workflow
retention distribution manifest record = distribution-layer distribution manifest record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention distribution package closeout record:
formal closure of retention distribution package workflow

retention distribution manifest record:
distribution-layer distribution manifest record
```
