# Retention Terminal Permanent Closure Notice Records

PFEM retention terminal permanent closure notice records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent public register closeout record = formal closure of retention terminal permanent public register workflow
retention terminal permanent closure notice record = terminal-permanent-closure-notice layer terminal permanent closure notice record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent public register closeout record:
formal closure of retention terminal permanent public register workflow

retention terminal permanent closure notice record:
terminal-permanent-closure-notice layer terminal permanent closure notice record
```
