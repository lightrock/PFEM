# Retention Notarization Verification Receipts

PFEM retention notarization verification receipts add the next retention endcap boundary.

The boundary is:

```text
retention notarization record = post-closure notarization record
retention notarization verification receipt = evidence that notarization refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention notarization record:
post-closure notarization record

retention notarization verification receipt:
evidence that notarization refs/digest were checked
```
