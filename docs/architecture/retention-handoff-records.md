# Retention Handoff Records

PFEM retention handoff records add the next retention handoff/export boundary.

The boundary is:

```text
retention export closeout record = formal closure of retention export workflow
retention handoff record         = handoff event for verified retention export
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention export closeout record:
formal closure of retention export workflow

retention handoff record:
handoff event for verified retention export
```
