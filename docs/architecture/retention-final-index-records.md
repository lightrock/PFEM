# Retention Final Index Records

PFEM retention final index records add the next retention endcap boundary.

The boundary is:

```text
retention endcap closeout record = formal closure of retention endcap workflow
retention final index record = post-closure final index record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention endcap closeout record:
formal closure of retention endcap workflow

retention final index record:
post-closure final index record
```
