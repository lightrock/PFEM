# Retention Access Grant Records

PFEM retention access grant records add the next retention access/release boundary.

The boundary is:

```text
retention access publication closeout record = formal closure of retention access publication workflow
retention access grant record = access-grant layer access grant record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention access publication closeout record:
formal closure of retention access publication workflow

retention access grant record:
access-grant layer access grant record
```
