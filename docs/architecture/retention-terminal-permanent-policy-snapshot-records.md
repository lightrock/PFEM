# Retention Terminal Permanent Policy Snapshot Records

PFEM retention terminal permanent policy snapshot records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent access control closeout record = formal closure of retention terminal permanent access control workflow
retention terminal permanent policy snapshot record = terminal-permanent-policy-snapshot layer terminal permanent policy snapshot record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent access control closeout record:
formal closure of retention terminal permanent access control workflow

retention terminal permanent policy snapshot record:
terminal-permanent-policy-snapshot layer terminal permanent policy snapshot record
```
