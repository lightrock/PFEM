# Archive Index Closeout Records

PFEM archive index closeout records add the next archive/preservation boundary.

The boundary is:

```text
archive index verification receipt = evidence that archive index refs/digest were checked
archive index closeout record      = formal closure of the archive index workflow
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
archive index verification receipt:
evidence that archive index refs/digest were checked

archive index closeout record:
formal closure of the archive index workflow
```
