# Retention Publication Certificate Records

PFEM retention publication certificate records add the next retention post-access boundary.

The boundary is:

```text
retention access completion closeout record = formal closure of retention access completion workflow
retention publication certificate record = publication-certificate layer publication certificate record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention access completion closeout record:
formal closure of retention access completion workflow

retention publication certificate record:
publication-certificate layer publication certificate record
```
