# Retention Registry Records

PFEM retention registry records add the next retention closure boundary.

The boundary is:

```text
retention certificate closeout record = formal closure of certificate workflow
retention registry record             = registry entry for the closed retention certificate
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention certificate closeout record:
formal closure of certificate workflow

retention registry record:
registry entry for the closed retention certificate
```
