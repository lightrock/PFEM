# Retention Report Records

PFEM retention report records add the next retention reporting/publication boundary.

The boundary is:

```text
retention rollup closeout record = formal closure of the retention rollup workflow
retention report record          = report drafted from the verified retention rollup
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention rollup closeout record:
formal closure of the retention rollup workflow

retention report record:
report drafted from the verified retention rollup
```
