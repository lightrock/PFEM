# Preservation Records

PFEM preservation records add the next archive/preservation boundary.

The boundary is:

```text
archive lifecycle closeout record = final closure of the archive lifecycle
preservation record              = ongoing preservation state for archived artifacts
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
archive lifecycle closeout record:
final closure of the archive lifecycle

preservation record:
ongoing preservation state for archived artifacts
```
