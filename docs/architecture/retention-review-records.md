# Retention Review Records

PFEM retention review records add the next preservation/retention boundary.

The boundary is:

```text
preservation chain verification receipt = evidence that preservation-chain summary/digest was checked
retention review record                = review decision for ongoing preservation/retention
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
preservation chain verification receipt:
evidence that preservation-chain summary/digest was checked

retention review record:
review decision for ongoing preservation/retention
```
