# Retention Access Grant Verification Receipts

PFEM retention access grant verification receipts add the next retention access/release boundary.

The boundary is:

```text
retention access grant record = access-grant layer access grant record
retention access grant verification receipt = evidence that access grant refs/digest were checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention access grant record:
access-grant layer access grant record

retention access grant verification receipt:
evidence that access grant refs/digest were checked
```
