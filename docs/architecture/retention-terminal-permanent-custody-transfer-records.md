# Retention Terminal Permanent Custody Transfer Records

PFEM retention terminal permanent custody transfer records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent chain rollup closeout record = formal closure of retention terminal permanent chain rollup workflow
retention terminal permanent custody transfer record = terminal-permanent-custody-transfer layer terminal permanent custody transfer record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent chain rollup closeout record:
formal closure of retention terminal permanent chain rollup workflow

retention terminal permanent custody transfer record:
terminal-permanent-custody-transfer layer terminal permanent custody transfer record
```
