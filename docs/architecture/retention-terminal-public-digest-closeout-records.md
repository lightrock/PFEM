# Retention Terminal Public Digest Closeout Records

PFEM retention terminal public digest closeout records add the next retention publication closeout boundary.

The boundary is:

```text
retention terminal public digest verification receipt = evidence that terminal public digest refs/digest were checked
retention terminal public digest closeout record = formal closure of retention terminal public digest workflow
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text

evidence that terminal public digest refs/digest were checked

retention terminal public digest closeout record:
```
