# Retention Terminal Status Records

PFEM retention terminal status records add the next retention finalization boundary.

The boundary is:

```text
retention finalization closeout record = formal closure of retention finalization workflow
retention terminal status record       = terminal status for the finalized retention workflow
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention finalization closeout record:
formal closure of retention finalization workflow

retention terminal status record:
terminal status for the finalized retention workflow
```
