# Retention Permanent Archive Accession Summary Records

PFEM retention permanent archive accession summary records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent closure notice closeout record = formal closure of retention terminal permanent closure notice workflow
retention permanent archive accession summary record = permanent-archive-accession-summary layer permanent archive accession summary record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent closure notice closeout record:
formal closure of retention terminal permanent closure notice workflow

retention permanent archive accession summary record:
permanent-archive-accession-summary layer permanent archive accession summary record
```
