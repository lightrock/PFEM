# Retention Terminal Permanent Archive Package Records

PFEM retention terminal permanent archive package records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal archival accession closeout record = formal closure of retention terminal archival accession workflow
retention terminal permanent archive package record = terminal-permanent-archive-package layer terminal permanent archive package record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal archival accession closeout record:
formal closure of retention terminal archival accession workflow

retention terminal permanent archive package record:
terminal-permanent-archive-package layer terminal permanent archive package record
```
