# Retention Archive Anchor Records

PFEM retention archive anchor records add the next retention endcap boundary.

The boundary is:

```text
retention notarization closeout record = formal closure of retention notarization workflow
retention archive anchor record = post-closure archive anchor record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention notarization closeout record:
formal closure of retention notarization workflow

retention archive anchor record:
post-closure archive anchor record
```
