# Archive Manifest Records

PFEM archive manifest records add the next lifecycle/archive boundary.

The boundary is:

```text
custody lifecycle closeout record = final closure of the custody lifecycle
archive manifest record          = manifest of lifecycle artifacts prepared for archive
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody lifecycle closeout record:
final closure of the custody lifecycle

archive manifest record:
manifest of lifecycle artifacts prepared for archive
```
