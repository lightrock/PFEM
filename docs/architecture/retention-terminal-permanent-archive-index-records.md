# Retention Terminal Permanent Archive Index Records

PFEM retention terminal permanent archive index records add the next permanent-archive retention boundary.

The boundary is:

```text
retention terminal permanent archive package closeout record = formal closure of retention terminal permanent archive package workflow
retention terminal permanent archive index record = terminal-permanent-archive-index layer terminal permanent archive index record
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
retention terminal permanent archive package closeout record:
formal closure of retention terminal permanent archive package workflow

retention terminal permanent archive index record:
terminal-permanent-archive-index layer terminal permanent archive index record
```
