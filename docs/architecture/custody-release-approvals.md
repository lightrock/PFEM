# Custody Release Approvals

PFEM custody release approvals add the next custody boundary.

The boundary is:

```text
custody release request   = request to release artifacts
custody release approval  = authorization to execute that release
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
custody release request:
request to release artifacts

custody release approval:
authorization to execute that release
```
