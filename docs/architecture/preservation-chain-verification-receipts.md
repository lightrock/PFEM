# Preservation Chain Verification Receipts

PFEM preservation chain verification receipts add the next preservation/retention boundary.

The boundary is:

```text
preservation chain record                = linked preservation cycle summary
preservation chain verification receipt  = evidence that preservation-chain summary/digest was checked
```

## Why this exists

This keeps one PFEM responsibility separate from the next.

Plain English:

```text
preservation chain record:
linked preservation cycle summary

preservation chain verification receipt:
evidence that preservation-chain summary/digest was checked
```
