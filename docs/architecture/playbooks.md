# Playbooks

PFEM playbooks are reusable procedures.

Action records answer:

```text
What should happen next?
```

Playbooks answer:

```text
How should this recurring kind of action usually be performed?
```

## Why separate playbooks from action records?

An action record is an instance.

A playbook is a reusable procedure.

Keeping them separate prevents PFEM action records from becoming bloated instruction manuals.

## Playbooks are for

- repeatable monitoring steps
- review steps
- handoff steps
- escalation steps
- correction/supersession steps
- archive/disposition steps

## Playbooks are not

- dispatch systems
- legal authority
- incident command plans
- proof that a step was completed

A playbook should be cited by an action record when a reusable procedure applies.
