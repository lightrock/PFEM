# docs/AGENTS.md

Documentation in this folder is the human-readable source of PFEM doctrine.

Rules:

- Keep public language neutral and reusable.
- Explain architecture in deployment-shape terms, not named organizations.
- Prefer clear definitions over marketing language.
- When introducing a concept, add it to the glossary or architecture model.
- Keep evidence, observation, finding, alert, package, rollup, and report boundaries explicit.
- Architecture decisions belong in `docs/decisions/` when they become significant.
