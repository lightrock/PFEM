# Prompt: Add a PFEM Adapter

Task: create or revise a PFEM adapter.

Read first:

- `docs/architecture/adapter-model.md`
- `contracts/adapter-contract.md`
- `ai/adapter-rules.md`
- `schemas/adapter_manifest.schema.json`

Output should include:

- adapter manifest
- README
- decoder stub
- normalizer stub
- health stub
- sample raw input
- sample normalized output
- contract test notes

Do not let the adapter own deployment policy or final alert decisions.
