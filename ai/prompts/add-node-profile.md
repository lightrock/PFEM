# Prompt: Add a PFEM Node Profile

Task: create or revise a PFEM node profile.

Read first:

- `docs/architecture/node-profile-model.md`
- `contracts/node-profile-contract.md`
- `ai/node-profile-rules.md`
- `schemas/node_profile.schema.json`

Use neutral deployment-shape language.

The profile should configure capabilities, adapters, dashboard mode, review gates, sharing behavior, and offline behavior. It must not redefine core domain objects.
