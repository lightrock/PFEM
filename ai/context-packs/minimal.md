# PFEM Minimal Context Pack

PFEM means Polycentric Federated Evidence Mesh.

Core boundaries:

- raw evidence
- normalized observation
- finding
- alert
- evidence package
- dashboard action
- federation message
- rollup summary
- report

Adapters translate source-specific inputs into PFEM contracts. Profiles configure deployment shape. Rollups are summaries, not complete local truth. Use neutral deployment-shape language.
