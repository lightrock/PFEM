# ai/AGENTS.md

The `ai/` folder contains instructions, rules, checklists, and context packs for AI assistants.

Rules:

- Keep these files concise and operational.
- Point to doctrine files instead of duplicating everything.
- Do not hide major architecture rules only in AI instructions.
- If an AI rule becomes project doctrine, move or mirror it into `docs/architecture/`.
- Prompt files should produce reviewable outputs, not silent mutations of operational data.
